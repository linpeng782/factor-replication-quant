# 长端动量 2.0：长期、低换手、多头显著的量价因子（开源证券 2022-11-26，开源量化评论 67）

原文：`research-paper-reproduction/parsed_output/开源证券/20221126-开源证券-开源量化评论（67）：长端动量2.0，长期、低换手、多头显著的量价因子/full.md`

## 核心逻辑（line 148-160）

A 股长端涨跌幅（Ret160）整体呈**反转**，原因是高振幅交易日的涨跌幅度显著更大、
主导了长端涨跌幅（Ret_high 与 Ret160 相关性 84.8%，Ret_low 仅 4.9%），而高振幅日
正是投资者**过度反应**之处 → 强反转。把低振幅日的涨跌幅单独加总（Ret_low）就能
剥离过度反应、露出真正的**动量**效应；回看天数越长动量越强，160 日附近最优。

## 因子构建步骤

**长端动量 1.0（表1，line 174）**
1. 回溯最近 160 个交易日
2. 计算每日振幅 = 最高价/最低价 − 1
3. 取振幅较低的 70% 交易日，涨跌幅加总

**长端动量 2.0（表2，line 198）** —— 四处改进（line 188-194）
1. 回溯最近 160 个交易日
2. **剔除涨跌停及停牌交易日数据**（停牌日振幅 0 会被误划入低振幅组但涨跌幅无意义；
   涨跌停日振幅受交易机制限制，无法反映交易活跃度）
3. 每日振幅 = **(最高价 − 最低价) / 前收盘价**（切割指标改进）
4. 取振幅较低的 70% 交易日，**日超额收益**（涨跌幅 − 市场涨跌幅均值）加总 = `AlphaRet_low`
5. `AlphaRet_low` 做 **20 日反转中性**（对 Ret20 截面回归取残差）→ 长端动量 2.0

改进 3 的动机（line 192）：股票日收益含市场 beta，横截面对比时若各股参与切割的
日期集合不同，beta 会污染相对排序 → 先减市场均值。
改进 4 的动机（line 194）：`AlphaRet_low` 在反转因子上正暴露（相关性 18.6%），
与反转因子有效性此消彼长 → 做 20 日反转中性。

## 复现口径选择（研报未明确处）

1. **"市场涨跌幅均值"** = 当日全 A 个股日收益的**等权截面均值**（非指数收益）→ 用
   `transform.cs_demean`（按 date 去均值）实现。
2. **涨跌停判定**：`close ≥ limit_up − 1e-4` 或 `close ≤ limit_down + 1e-4`，
   涨跌停价取 dquant `get_limit`，与**未复权** close 同口径比较。
   （combo_mask 只有 `is_limit_up`，缺跌停 → 自建 `normal_day_panel`）
3. **停牌判定**：combo_mask 的 `is_suspended`。
4. **切割比例**：`k = floor(有效日数 × 0.7)`；有效日 < 80（=window/2）→ 因子 NaN。
5. **振幅/收益复权**：一律用后复权价（2.0 振幅分母是前收，跨除权日必须后复权）。
6. **20 日反转中性**：截面 OLS `AlphaRet_low ~ Ret20`（含截距）取残差，Ret20 用
   `RET20_PANEL_PATH`（close-close 后复权 20 日收益），与 APM 去动量同一算子。
7. 方向：动量因子为**正向**（direction = +1），与研报 RankIC 正号一致。
