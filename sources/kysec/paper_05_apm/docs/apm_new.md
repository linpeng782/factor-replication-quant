# APM 因子族（凤鸣朝阳 + 开源微观结构系列5）— 复现沉淀

> 覆盖本组 5 因子（ovp/avp/apm_raw/apm_new/apm_1）的总沉淀。spec 见同级 specs/；论文蒸馏见 ../paper.md。

## 1. 因子定义（数学 + 直觉）
**直觉（凤鸣朝阳 L44/L250；进阶版 L157/L218）**：日内不同时段收益对未来收益的预测性不同——
**隔夜正向且稳定、下午负向、上午全样本正但 2019 后失稳**。APM 捕捉"知情交易者的方向"：
因子值越大 → 知情者偏多 → 次月收益越高（**direction=+1，正向选股，非反转**）。

**两类构造：**
- **回归型 APM**（apm_raw/apm_new/apm_1）：近 20 日两段（段1 vs 下午）个股收益对**指数**(000985)同段收益做 40 点 OLS 取残差 → δ_t=ε_seg1−ε_pm → stat=mean(δ)/(std(δ)/√n) → 截面对 Ret20 回归去动量。apm_raw 段1=上午，apm_new 段1=隔夜，apm_1=隔夜 vs 尾盘。
- **累积差型**（ovp/avp，"W式切割"，无回归）：OVP=Σ隔夜−Σ下午（20日）；AVP=Σ上午−Σ下午。

## 2. 实现（新建件）
- **reducer `minute_apm_segments`（apm_v1, warmup=1）**：逐股产 4 段日频收益 ret_overnight/ret_am/ret_pm/ret_pm_late。隔夜跨日价由 load_adjusted_minute_window 后复权（cf 累积口径，今开/昨收同口径），单股手算 4 列全 bit-exact。
- **新 L3 算子 `rolling_ts_regress`**：矢量化 sliding_window_view + 闭合式 OLS，逐股 20 日滚动 40 点回归→δ→stat。内部读 INDEX_SEGMENTS_PATH 的指数段收益。
- **新 L3 算子 `load_panel`**：加载本地宽表（Ret20 后复权面板）merge 进长表，供 cross_section_regress 去动量。
- **数据线 `index_segments.py`**：get_price('000985','1m') → 日频四段收益。⚠️ 指数分钟数据 rqdatac 仅从 2011-08 起，故 APM 早于 2011-09 为 NaN（不影响 2016-2025 评估）。

## 3. 复现结果（月频 RankIC / 年化 ICIR，按论文口径：月末截面 vs 次月收益）
**论文窗口 2014-2019：**
| 因子 | 我 RankIC | 我 ICIR | 论文 ICIR | 论文方向 |
|---|---|---|---|---|
| ovp | +5.12% | **+3.54** | 4.17 | +（最强）|
| apm_new | +4.72% | **+3.17** | **3.17** | + |
| apm_1 | +3.80% | +2.79 | (强) | + |
| apm_raw | +1.54% | +1.04 | 2.07 | + |
| avp | -0.40% | -0.22 | 0.15 | ≈0（最弱）|

全样本 2016-2025：ovp +2.92 / apm_new +2.76 / apm_1 +2.64 / apm_raw +0.12 / avp -1.19。

**方向全部对齐**（真因子正相关、AVP≈0）；**APM_new ICIR 精确命中论文 3.17**；**相对排序完全复刻**：OVP>APM_new>APM_1>APM_raw>AVP。

## 4. 非平凡洞察（最值钱）
1. **方向反直觉但实证为正**：初始误把 APM 当反转因子（direction=-1），实测 dir=+1。论文核心是"隔夜=informed、正向持续；下午=noise、负向反转"，APM=隔夜−下午 自然正相关。**复现时务必先验证方向再下论断**（凤鸣朝阳 L250 明言正相关）。
2. **apm_raw 在 2016-2025 趋近 0（ICIR 0.12），恰好复现论文核心论点**——上午段预测性 2019 后失效；而隔夜型 apm_new 全程稳定（2.76）。这是"复现验证了论文为何要进阶"的有力证据，比单点数值更说明问题。
3. **本篇落地了设计 §10 预判的「②市场参照序列 + 滚动回归」模式**：指数数据线 + rolling_ts_regress 两块新基建。OVP/AVP 证明"累积差型"无需指数/回归即可拿下论文最强因子（OVP ICIR 3.54），是最低成本切入点。
4. **回归稳健性**：rolling_ts_regress 用闭合式 OLS（n·ΣXY−ΣX·ΣY）/（n·ΣX²−ΣX²），矢量化无矩阵分解，5000 股全史秒级。

## 5. 与基准差距 + 改进路径
- apm_raw 我 1.04 vs 论文 2.07：我窗口 2014-2019 已含 2019 失效期，且论文样本 2013.5 起略早。方向一致。
- 量纲差异：论文月频 RankIC ~5-9%，我月频 ~3-5%，同量级（评估期/股票池/正交方式略异）。
- 改进：①APM_1 之外可加 APM_2(早盘vs尾盘)/APM_3(中段) 变体；②指数可试中证500(000905)看是否如论文在500内最优；③OVP 可与 tide/dazzle 做相关性看增量。
