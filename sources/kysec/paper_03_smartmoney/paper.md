## 核心直觉（原始版 L114-115）
机构（"聪明钱"）单笔大单、报价激进 → 分钟级表现为「价格波动大、成交量未必大」。
用"聪明度" S 识别这些分钟，看聪明钱的成交均价相对全体的位置：
**Q = VWAP_smart / VWAP_all**。
- Q > 1：聪明钱买在**相对高位** → 逢高出货/悲观 → 后续下跌；
- Q < 1：聪明钱买在**相对低位** → 逢低吸筹/乐观 → 后续上涨。
→ **direction = -1**（Q 高未来弱）。

## 构造（逐股、10 日池化，无指数无截面）
1. 取该股过去 **lookback=10** 个交易日的全部分钟（R_t=分钟收益, V_t=分钟成交量）。
2. 聪明度 **S = |R_t| / V_t^β**（原始 L94-100：β=0.5 即 |R|/√V；2.0 L211-263：**β=0.1** 最优）。
3. 按 S **降序**排，取**成交量累计占比前 cutoff=20%** 的分钟 = 聪明钱交易（原始 L102 / 2.0 L95-103）。
4. VWAP_smart = 聪明钱分钟量加权均价；VWAP_all = 全部分钟量加权均价。
5. **Q = VWAP_smart / VWAP_all**（原始 L108-114 / 2.0 L99）。
6. 截面五分组，Q 最小组做多。可再对市值/动量/行业截面回归取残差（原始 L278-283：残差 IR 2.07）。

## 2.0 相对原始版的改进（2.0 L155-287）
- **核心：β 0.5 → 0.1**（L211/236/263）：降低成交量权重、强化 |R|，IR 1.7 → **3.67**，IC 均值 -0.03 → -0.055。
- 试过 **S3 = |R|/ln(V)**（L269-279，表2）：IR **3.74**，最优变体。
- cutoff 测过 15%（IR 3.35 略优于 20% 的 3.27），最终仍用 20%（L319-320）。

## 数据与计算模式
- **纯逐股分钟归约**（mode ① + 跨日池化）：无需指数、无需截面（截面只在评估分组）。
- **跨日池化在 reducer 内**：10 日窗口不可拆成"日内+L3滚动"→ 进 reducer，warmup=lookback=10。
- 复权稳健：S 用 |R|（日内分钟比值，复权抵消）；VWAP 比值 Q 也是同窗口比值。

## 工程选择 / 待验证
- **预过滤（原始注[2] L483）**：排序前先剔除分钟成交量最小的 1/5，避免超低量分钟 S 虚高。
  ⚠️ 当前 reducer **未做**此预过滤；2.0 论文未强调。先按现状跑，Q 对不齐再加。
- 首分钟收益：日内 pct_change，每日首分钟 NaN（不参与 S 排序，但计入 VWAP_all）。
- cutoff 边界：含"跨过阈值那一分钟"（贪心纳入，与原始图表1一致）。
