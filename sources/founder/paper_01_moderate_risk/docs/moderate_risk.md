# 适度冒险因子族（方正微观结构① 成交量激增 alpha）

> 覆盖本组 7 个因子的总沉淀。spec 见同级 specs/；论文蒸馏见 ../paper.md。

## 1. 因子定义（数学 + 经济直觉）
日内"成交量激增"= 分钟成交量增量 ΔV[m]=V[m]−V[m−1] 超过当日 mean+1·std 的时刻。两条代理：
- **日耀眼波动率** `dazzle_vol` = 每个激增时刻"耀眼5分钟"[m,m+4] 内分钟收益率 std 的当日均值（激增引起的价格**波动**）。
- **日耀眼收益率** `dazzle_ret` = 激增时刻**当分钟收益率**的当日均值（激增引起的价格**变动**）。

经济直觉：成交量激增=新信息到达。价格反应**适度最好**——反应不足(没被认可)或反应过度(趋同/过度冒险)都预示未来反转。故"适度"= **|日值 − 当日截面均值|**（距市场平均的距离），距离越大→越不适度→未来收益越弱，**direction=−1**。

7 因子 = {波动率, 收益率} × {月均(mean20), 月稳(std20), 月耀眼(二者合成)} + 适度冒险(两条月耀眼合成)。

## 2. 研报歧义 + 工程选择
1. **开收盘剔除分钟数**：论文仅言"剔除开盘和收盘"未给数 → 复用 tide 的 `drop_open=4 / drop_close=7`（同一分钟数据上已验证，且论文用例的激增时刻 9/10/88/200 仍落在保留区 [4,232]）。
2. **"等权合成"口径**：两分量量级/单位不同（mean vs std；vol vs ret）→ 各取**截面 pct-rank 后平均**（与 `tide_complete` 一致，对量级稳健）。两条 combo 已是 rank∈[0,1] 同尺度，适度冒险直接平均。
3. **std 自由度** ddof=1（样本 std，对齐 pandas rolling std）。耀眼窗口贴近收盘时 [m,m+4] 截断到当日末分钟。
4. **位序而非 minute_of_day**：相邻按剔除开收盘后的位序算（ΔV/收益首位无前值置 NaN），午休 gap 作单个内部相邻点（与论文"分钟频序列"一致）。

## 3. 实现高层逻辑（新建件）
- **reducer `minute_dazzle`（cache_key=dazzle_v1, warmup=0）**：per-stock 日内归约产 dazzle_vol/dazzle_ret。复权稳健（收益/ΔV 为日内比值/同日量，cf 抵消）→ **不依赖 stock-ex-factors**，本机缺 daily/ 也能正确全史首建。
- **L3 新算子能力**：`transform` 增 `cs_demean`(按 date 截面去均值) + `abs` → 适度=cs_demean∘abs。复用 transform 既有 groupby 框架（同 winsorize/zscore），未开新算子文件。
- spec 图：minute_dazzle → cs_demean+abs → rolling mean20/std20 → rank(截面pct)+compute 平均。

## 4. 复现结果（neu 生产版，2016-01~2025-12，IC5d=Spearman primary）
| 因子 | neu IC5d | 单调性 | 论文 RankIC(2013-22月频) |
|---|---|---|---|
| 月均耀眼波动率 | 5.22% | +0.884 | -6.60% |
| 月稳耀眼波动率 | 7.24% | +0.938 | -7.87% |
| 月耀眼波动率 | 6.82% | +0.925 | -7.63% |
| 月均耀眼收益率 | 7.58% | +0.882 | -8.62% |
| 月稳耀眼收益率 | 7.20% | +0.898 | -8.00% |
| 月耀眼收益率 | 7.56% | +0.893 | -8.53% |
| **适度冒险** | **7.77%** | **+0.931** | **-8.89%** |

方向全部 −1（与论文一致）。量级与论文同邻域（窗口/换手频率不同口径），**相对排序精确复刻论文**：收益率线>波动率线、std 分量≥mean 分量、适度冒险全表最强。

## 5. 非平凡洞察（最值钱）
1. **"适度"= |截面去均值| 是本仓首个"折叠型"截面因子**——把原始日值映射成"距市场均值的距离"。值得注意：折叠后仍有强单调 IC(+0.93)，说明"偏离市场平均反应程度"本身就是强反转信号，**符号方向由 abs 之外的截面排序承载**（abs 之后越大越差）。这验证了 `hf_factor_factory_design.md` §10 预判的"①+截面"模式可落地。
2. **reducer 对复权不敏感** → 在缺 ex_factors 的机器上也能 bit 正确建库（与 tide 同源洞察），降低了部署数据依赖。
3. **系统压测结论**：一篇全新研报 = 写 1 个 reducer(~110 行) + 扩 transform 2 个 method + 7 个 spec；单股手算对账一次通过，全史首建 96 核 ~76min，7 因子并发评估一把出。验证"新研报≈写 reduce+spec"的工厂设计成立。

## 6. 与基准差距 + 改进路径
- 我的 IC 略低于论文（如适度冒险 7.77% vs 8.89%），差异主要来自：①评估窗口(2016-2025 vs 2013-2022)；②换手/IC horizon(5d vs 月频)；③论文市值行业正交在测试内做，本仓 neu 是预先中性化。方向与排序一致已证复现成立。
- 改进路径：①参数变体（耀眼3分钟 `__w3`、surge_k 敏感性）建并列 spec；②激增阈值可改 robust（中位数+MAD）抗异常；③与 tide/prv 因子做相关性/正交（factor_correlation.py）看增量信息。
