## 1. 因子定义

研报字面：

> 取过去 8 期单季度净利润为 y，以 8 个报告期间累计间隔天数为 x，
> 分别对 x 和 y 做 zscore 处理后，做二次回归 ax²+bx+c，
> 其中 a 即为因子值；前 4 期和后 4 期相关性过高时置 NaN；不足 8 期置 NaN。

数学形式：

```
对每只股票、每个交易日：
  y = [净利润_mrq_0, _1, _2, ..., _7]                         # 8 个单季净利
  x = 8 个报告期累计间隔天数（从最早期 t_0 起算，t_0=0）

  y_z = zscore(y, ddof=1)        # 行向
  x_z = zscore(x, ddof=1)        # 行向

  fit:    y_z = a·x_z² + b·x_z + c   （8 点 OLS）
  因子值: a

  fb_corr = Pearson(y_z[0..3], y_z[4..7])
  if |fb_corr| > 0.9: 因子值 = NaN
  if 数据不足 8 期:    因子值 = NaN
```

经济直觉：**a 衡量"加速度"，比 YoY/QoQ 多看一阶导**。
- a > 0（凸）：净利润正在加速增长
- a < 0（凹）：增长在减速
- a ≈ 0：近似线性，无加速度信号

方向 +1：a 越大 → 加速越明显 → 预期收益越高。

## 2. 研报描述的 4 处歧义与我们的选择

研报描述简短，至少 4 处需要工程决策：

| # | 歧义点 | 我们的选择 | 理由 |
|---|---|---|---|
| 1 | x 用什么？真实公告日 / 等距 0..7 / 季度结束日 | **等距 0..7（v1）** | 单股测试显示 zscore 后形状差异小（Δa 5-57%），符号和排名不变；v2 真公告日待对比 |
| 2 | zscore 行向还是截面 | **行向** | "时序回归"语义自然解读；row_polyfit 算子支持 |
| 3 | "前 4 vs 后 4 相关性"具体定义 | **Pearson(y_z[0..3], y_z[4..7])** | 最直白的解读，单股测试验证它确实在过滤季节性 |
| 4 | "过高"阈值 | **`|corr| > 0.9`** | 研报未明确；0.9 是常见严格阈值；用 abs 同时过滤强正/强负相关 |

## 3. ⭐ 关键洞察：前 4 / 后 4 相关性过滤 = **季节性过滤器**

这是复现这个因子时**最非平凡**的一个发现，也是为什么覆盖率只有 ~50%。

### 我之前的误解

最初以为这个过滤是为了**剔除"线性形态"被误判为二次的样本**——避免直线被强行拟合成有微小弯度的二次曲线。这个解读语义上说得通但在 A 股上几乎没用。

### 实际上它在过滤什么

A 股很多公司（银行、消费、制造业）净利润有**强季度性周期**——同样的"Q1 高、Q4 低"或"Q4 高、Q1 中等"模式年复一年重复。**8 期数据等于 2 个完整季度循环，前 4 期和后 4 期形状必然高度相似**，相关性 > 0.9 是常态。

这种情况下二次回归拟合出来的 a，**实际反映的是 8 个点的季节性周期形状，不是真正的"加速度"**。a 数值是季节性的伪信号，没 alpha。

### 三股冒烟测试的直接证据

锚定 trade_date = 2024-12-31：

| 股票 | 行业 | y_z 形态 | fb_corr | 是否过滤 |
|---|---|---|---|---|
| 平安银行 | 银行 | `[低,高,低,高 / 低,高,低,高]` 完美 Q1 高 Q4 低周期 | **+0.978** | ✗ 过滤 |
| 贵州茅台 | 消费 | `[中,高,低,低 / 中,高,低,低]` 完美 4 季模式 | **+0.990** | ✗ 过滤 |
| 宁德时代 | 制造 | 前 4 是周期；后 4 是"业绩水位整体抬升 + 季节性减弱" | +0.741 | ✓ 保留 |

宁德时代是唯一保留的——单季净利数据：

```
2022Q4: 138 亿  ← 高
2023Q1: 101 亿  ← 低 (Q1 季节性低)
2023Q2: 114 亿  ← 中
2023Q3: 110 亿  ← 中
─────────────────
2023Q4: 142 亿  ← 高 (符合 Q4 高)
2024Q1: 112 亿  ← 中 (不再像 2023Q1 那么低 → 季节性松动)
2024Q2: 137 亿  ← 高 (突破原 Q2 中等 → 加速信号)
2024Q3: 139 亿  ← 高 (突破原 Q3 中等 → 持续加速)
```

后 4 期不再复读前 4 期，**业绩水位整体抬升 + 季节性减弱**。a = +0.481 二次项凸 → 因子值高。

### 这条洞察对全市场结果的预测

**预测**：覆盖率应该在 30-50%（大多数 A 股有季节性会被过滤）；**实测 51.2%**——预测吻合。

剩下 ~50% 的样本是"业绩季节性被打破 / 业绩水位突变"的少数股票。**这部分样本的 alpha 应该高度纯净**——不是噪声，是真正的"加速增长"信号。

实测分层：

```
G1: -1.29% / 年（被认为"减速"组）
G2: +1.46%
G3: +3.31%
G4: +4.49%
G5: +8.85%（"加速"组）
LongShort: +10.23% / 年, vol 4.37%, Sharpe 2.34
单调性 +0.979（接近完美）
```

**Sharpe 2.34 极强、单调性接近完美 —— 因子设计意图实现**。

## 5. 真实公告日 vs 等距 x 的对照实验

### 米筐 PIT 数据观察

`get_pit_financials_ex(statements='all')` 一次性返回每个 quarter 的所有版本（原始 + 重述）。每个版本有自己的 info_date（公告日）。原始公告日 = `min(info_date)` per quarter。

用 000001.XSHE 实测：8 期累计天数 `[0, 47, 168, 230, 372, 408, 526, 590]`，相邻间隔 `[47, 121, 62, 142, 36, 118, 64]` 天，**均值 84.3 std 41.7（相对 std 50%）**——**严重非等距**。

A 股公告日的统一节奏：
- 年报到一季报：~30 天（紧凑）
- 一季报到半年报：~120 天（疏松）
- 半年报到三季报：~60 天
- 三季报到下个年报：~150 天

### 等距 vs 真实 x 的影响

三股锚定 2024-12-31 实测：

| 股票 | a (真实 x) | a (等距 x) | Δa | 相对差 |
|---|---|---|---|---|
| 平安银行 | +0.0557 | +0.0239 | -0.032 | 57% |
| 贵州茅台 | -0.1601 | -0.1304 | +0.030 | 19% |
| 宁德时代 | +0.4812 | +0.5070 | +0.026 | 5.4% |

**关键发现**：
1. **符号 / 排名保持不变**：截面排序前后一致
2. **Δa 大小和"信号强度"成反比**：弱信号股相对差大但贡献低；强信号股几乎不受影响
3. **过滤决策完全一致**：fb_corr 只依赖 y，不依赖 x

也就是说，**等距简化对截面排序的影响有限**，全市场 IC/ICIR 在等距版下应该接近真实公告日版。这次实测 ICIR 0.26 和 Sharpe 2.34 验证了这点——因子结构上是对的。

## 6. 与研报基准 ICIR=1.28 的差距分析

ICIR 0.26 vs 基准 1.28，差 ~5 倍。但 Sharpe 2.34 强 + 单调性 0.98 完美 → **不是因子构造错误，是 IC 量级的差距**。

按可能性排序：

### (1) 股票池差异（最可能）
基准 1.28 大概率是在中证 800 / 中证 1000 等已筛过的窄池子上做的。SUE / 加速度类因子对池子极敏感：
- 大票/中票：财务数据干净，加速度信号真实
- 小票/ST/科创/北交所：盈利数字噪声大、操纵频繁

我们用 `primary_index: ALL`（5549 只），稀释效应显著。**预期切到中证 800 ICIR 跳到 0.6-0.9 量级**。

### (2) 时段差异
研报多基于 2010-2018 样本期，A 股机构化前因子衰减慢。我们 2016-2025 含近期机构化加剧 + 量化竞争密集化的窗口。

### (3) 等距 x 精度损失
单股测试显示对截面排序影响有限，**不是主因**。

### (4) 阈值 0.9 是否合理
研报没说阈值。如果实际更松（如 0.85）会过滤更多季节性，剩下样本信号更纯，ICIR 可能上升；更严（如 0.95）会留下更多噪声样本，ICIR 下降。**待实验**。

## 8. 算子层贡献

这个因子驱动了 2 个新算子的诞生：

- **`row_polyfit`**（`core/operators/row_polyfit.py`）：行向多项式 OLS 回归，numpy 向量化闭式解，1300 万行 < 1 秒。带 `zscore_y=True` 默认（让跨股票截面因子的 a 系数可比）。
- **`row_correlate`**（`core/operators/row_correlate.py`）：行向 Pearson 相关，numpy 向量化。

两个算子都设计为通用形式（n 列任意），可被其他因子复用。预计 reg_pe_hist / reg_pb_gshe 也会用 row_polyfit。

## 9. 工程经验沉淀

### 9.1 单股冒烟测试是高 ROI 投资

走全市场前先用 3 只股票做端到端冒烟（不依赖项目算子，纯 numpy + rqdatac），10 分钟摸清因子真实行为。如果直接上全市场，会**误读 51% 覆盖率为 bug**，浪费时间排查不存在的问题。

### 9.2 LLM 暴露算子缺口的能力

第一轮 Kimi 不知道我们有 row_polyfit，**主动写出"假设算子也对 y 做 zscore"** 这句 thinking——LLM 帮我们发现了"x 自动 zscore 但 y 不 zscore"的设计不对称。后来给 row_polyfit 加 `zscore_y` 默认 true 修复。

### 9.3 米筐 PIT 语义陷阱

- `info_date` 是某个**版本数据**的公告日，不是固定的"原始公告日"
- `statements='latest', date=d` 返回截至 d 的最新版本（可能是重述）
- `statements='all'` 返回所有版本，需要 `min(info_date) per quarter` 才能拿原始公告日
- 这次踩了一次坑（误以为同一 quarter 的 info_date 不可信）
