# reg_pe_fy1 — 经久期调整的预期 PE

**类别**：价值/估值情绪 | **方向**：-1

## 研报释义（consensus.png）
1. 计算久期：久期 =(fy1·1+fy2·2+fy3·3)/(fy1+fy2+fy3)，实际计算时为提高利润覆盖度，
   会增加已发布年报后最近的 4 个报告期数据进行计算；
2. 计算 pe_fy1: pe_fy1 = 总市值 / fy1；
3. 将连续报告数不足 3 或 fy1 等于 0 的因子值置 nan；
4. 对久期和 pe_fy1 分别取 log 后求 60 日的 diff，然后以 delta(log(pe)) 为 y、
   delta(log(久期)) 为 x 做回归，取残差作为因子值。

## 工程实现
- fy1/fy2/fy3 = 可回溯区间(180天)内对第 1/2/3 预测年（net_profit_t/t1/t2 非空）做过预测的
  首序分析师数；久期 = 报告数加权预测期。
- pe_fy1 = market_cap / fy1 一致预期净利润（comp 当前年 Y 的预测，不滚动）。
- 连续报告数(n_fy1) < 3 或 pe<=0 置 NaN；log + 60 日 diff；逐日截面 OLS 取残差。
- 与 reg_pe_hist 同构（久期替代历史增速），方向 -1。
