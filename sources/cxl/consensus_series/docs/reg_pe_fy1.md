# reg_pe_fy1 — 经久期调整的预期 PE（估值情绪 · 预期版）

> 类别：价值 | 方向：−1 | 数据源：comp_indicators（pe_fy1）+ reports 明细（久期）

## 1. 定义
- **pe_fy1** = 总市值 / fy1 一致预期净利润（当前年 Y 的一致预期，不做 forward 滚动）。
- **久期** = (n_fy1·1 + n_fy2·2 + n_fy3·3)/(n_fy1+n_fy2+n_fy3)，n_fyk = 可回溯区间内对第 k
  预测年（报告级 net_profit_t/t1/t2 非空）做过预测的首序分析师数 → 衡量分析师"看多远"。
- log(pe_fy1) 与 log(久期) 各取 60 日 diff，逐日截面回归 Δlogpe ~ a+b·Δlogdur，**残差**即因子。
- 连续报告数 n_fy1 < 3 或 fy1≤0 置 NaN。

经济直觉：剥离"久期变化能解释的估值变动"后，残差 = 无久期支撑的估值情绪漂移；PE 异常上行
→ 高估 → 预期低收益，方向 −1（与图1 reg_pe_hist 同源，只是用分析师久期替代历史利润增速）。

## 3. 洞察 ⭐
**与 reg_pe_hist 的量级吻合是交叉验证。** reg_pe_hist（图1，历史增速版）cleaned IC
0.044/0.052/0.060；reg_pe_fy1（预期版）0.033/0.039/0.044——同量级、略低、同方向 −1、同
单调性梯度。两个独立数据源（PIT 财务 vs 分析师一致预期）经同一"log-diff-截面残差"管线
得到同源结果，强力佐证两者刻画的是同一类"无基本面支撑的估值情绪"，且实现无误。
