# 大单与小单资金流的 alpha 能力（开源微观结构系列 12）

> 来源：开源证券 2021-06-02《市场微观结构研究系列（12）：大单与小单资金流的alpha能力》
> 原文：parsed_output/开源证券/20210602-开源证券-市场微观结构研究系列（12）：大单与小单资金流的alpha能力/full.md
> 回测设置：全 A，五分组（因子值最大组-最小组对冲），月度调仓，2013.1 ~ 2021.4.30（表4 逐年绩效推断）

## 核心结论（§1, 原文 L128-147）

资金流按挂单金额分四档：超大单(>100万)、大单(20-100万)、中单(4-20万)、小单(<4万)（L130）。

1. **恐惧与贪婪的不对称性**（L132）：小单基本净流入、大单基本净流出（买入试探分批、卖出恐慌抛售）。
2. **大单与小单是关键变量**（L134）：超大单门槛过高、中单区间过窄，量级过小无考察意义；
   A 股逐笔成交金额中位数 ~0.8万、80%分位 ~2.4万 → 报告只聚焦**大单、小单**两档作为大/小订单代理。
3. **alpha 来源是大单的预见性**（L143）：截面上大单与小单资金流强负相关。成交额标准化下
   大单资金流因子 IC=+0.025（正向），小单 IC=-0.027（负向）。
   小单的负 alpha 源自"挤出效应"：四档净流入配平（Σ=0），大单是主动变量，配平压力几乎全由小单承接。

## 因子1：资金流强度 S1/S2/S3（§2, L149-159, 表1 L155）

以大单为例（buy/sell 为该档买入/卖出金额，T=20 个交易日回看）：

- S1 = Σ(buy_t - sell_t) / Σ Amount_t （成交额标准化，分母为个股总成交额）
- S2 = Σ(buy_t - sell_t) / Σ(buy_t + sell_t) （该档买卖总额标准化）
- **S3 = Σ(buy_t - sell_t) / Σ|buy_t - sell_t|** （净流入绝对值标准化，**最优**）

论文绩效（L159）：S3 下大单 IC 均值 0.042 / IR 2.69；小单 IC -0.03 / IR 1.37。
（S1 基准：大单 IR 1.84 / 小单 IR 1.09，表2 L201）

## 因子2：残差资金流强度（§3, L179-189）

大单 S 与 Ret20 同步正相关、小单负相关且 R² 较高（L169）。截面回归剥离涨跌幅：

    S_t = a + b * Ret20_t + ε_t        （L183 回归式；S 为 S3 口径资金流强度）

残差 ε 即残差资金流强度。论文绩效（L189, 表2 L201）：
- 大单残差：IC 0.054 / IR 3.96 / 年化 23.22% / 月胜率 83.84%
- 小单残差：IC -0.057 / IR 3.81 / 年化 21.41% / 月胜率 87.88%
- 样本内亦优：沪深300 多空 IR 大单 2.05 / 小单 2.27；中证500 大单 3.18 / 小单 2.47（L205）
- alpha 切分直觉（L215）：大单净流入伴随上涨 → 多头暴露反转的负 alpha；回归剔除后剩纯正向 alpha。

## 因子3：残差反转因子（§4, L227-249）

对称操作，用资金流强度回归反转因子、取残差替代传统反转：

    Ret20_t = a + b * S_t + ε_t        （L243 回归式）

论文绩效（L249, 表3 L261）：传统反转多空 IR 1.42；大单残差反转 1.87；**小单残差反转 2.26（最优）**，
多头/空头两侧均改善。沪深300 内小单残差反转 IR 2.05（表5 L277）、中证500 内 1.68（表6 L283）。

## 复现口径差异（工程决策，非论文内容）

1. **数据源**：论文用 Wind 口径（按挂单金额分档）；复现用聚源 DZ_TradingCapitalFlow
   （dquant `get_capital_flow(source="jy")`），按**单笔成交金额**分档，门槛同为 4万/20万/100万。
2. **value_range 映射**：实测 1=小单 2=中单 3=大单 4=特大单（scripts/verify_jy_capital_flow_tiers.py
   结构性验证：P≥420 元股票 range1 金额占比 0.07%≈0、茅台 range1 单日买入 15 股=3.75万 恰在 4 万门槛内；
   注意 dquant docstring 及其 API 文档写反了）。
3. **数据区间**：jy 分单数据 2009 年起；配平检验 bit 级通过（四档 buy+sell = 当日成交额）；
   缺行≈停牌（有成交但缺数的仅 ~4 只/日）→ 面板存续期内缺口填 0。
4. **本地落盘**：market-data/capital-flow-jy/{per-month,per-stock,panels}
   （dquant 端 cache_on_fetch=False，不落盘则每次全量查远端 MySQL ~1 小时）。

## ⚠️ 复现结论：jy 数据语义与研报不同，研报 alpha 方向不可复现

研报三大风格化事实在 jy 数据上**全部不成立**（2009-2026 实测）：

| 检验 | 研报（Wind 挂单口径） | jy 实测（成交额口径） |
|---|---|---|
| 图1 周净流入中位数 | 小单持续+、大单持续- | 小单-47万(23%周为正)、大单-291万、特大单+207万 |
| 图2 大小单截面相关 | 强负相关 | S3 秩相关 +0.096（近零） |
| 四档配平 Σ净流入≈0 | 基本满足（L143） | \|Σ净\|/成交额中位数 11.4% |

根源：**Wind 每笔成交按买卖双方各自的委托单金额分别归档**（买方档记 buy、卖方档记 sell，
恒配平），研报"小单净流入"=散户小委托接大单抛压。**jy 每笔成交按单笔成交金额归唯一档位、
按主动方向计入单侧**（Σ四档 buy+sell=成交额，不配平），"大单买入"=主动性大笔激进成交。
二者度量的是不同的经济对象——前者是订单规模结构，后者是主动交易行为。

jy 侧语义已由聚源官方表说明证实（DZ_TradingCapitalFlow，信息来源**恒生电子**）：
"展示…在不同**单笔成交额区间**的累计主买、主卖额及成交量情况。流入量（金额）：主动买成交，
即在卖盘上成交的外盘；流出量（金额）：主动卖成交，即在买盘上成交的内盘。"
另注意：官方数据范围为 **2012-07-09 至今**，我们实际拉到 2009-01 起的数据，
2009~2012.7 属官方口径外的回填段，使用需谨慎（研报区间 2013 起不受影响）。

实测四档 S3 的 20d IC 全为负（小单-0.050/中单-0.043/大单-0.037/特大单-0.054，研报区间），
即 jy 口径下"主动净买入"是反转/拥挤信号而非研报的"大单预见性"。复现产物 lb_flow_s3 反向
使用有效（IC5d 0.026 / 多空 Sharpe 1.35）；残差化（lb_flow_resid）后信号几乎消失。
严格复现研报需按挂单双边分档的资金流（Wind 或 L2 逐笔委托重构），jy MySQL 仅此一张分单表。
