# 输出要求
输出必须符合以下 YAML 结构，字段必须完整：

```yaml
factor:
  name: 英文因子名
  name_cn: 中文名
  category: 单因子/复合因子/辅助指标
  tags:
    public: "fundamental.xxx.xxx"
    private: "质量/景气/价值/成长/辅助"
  direction: 1  # 1=正向, -1=反向, 0=中性
  description: 一句话定义

formula:
  expression: 主公式字符串
  variables:
    - name: 变量名
      definition: 含义
      formula: 子公式（如有）

data_alignment:
  data_source: "米筐RQData"
  api: "get_pit_financials_ex"
  pit_mode: true
  announcement_field: "info_date"
  fields:
    - variable: 变量名
      rq_field: 米筐字段名
      table: 表名
      frequency: quarterly/daily
      data_type: cumulative/point_in_time
      notes: 备注

calculation_steps:
  - step: 1
    name: 步骤名称
    action: fetch/transform/compute/filter/rank/regress
    api: "get_pit_financials_ex"  # fetch时必填
    fields: [字段列表]  # fetch时必填
    method: 方法名  # transform时必填，如 diff/yoy/qoq/zscore
    formula: 公式字符串  # compute时必填
    condition: 条件字符串  # filter时必填
    lag_periods: 4  # yoy/qoq时必填
    output: 输出变量名

universe:
  primary_index: "000906.XSHG"
  filter:
    - type: market_cap_rank
      scope: within_universe
      top_n: 100
      field: market_cap
  exclusion:
    - "ST股票"
    - "停牌股票"
    - "上市不满60日"

backtest:
  rebalance:
    frequency: monthly
    trigger: month_end
  holding:
    count: 50
    weighting: equal
  benchmark: "000905.SH"
  transaction_cost:
    commission: 0.0015
    slippage: 0.0
  direction: 1

validation:
  expected_ic_mean: [0.02, 0.06]
  expected_ic_ir: [0.3, 0.8]
  expected_monotonicity: true
  expected_group_order: "group1 < group2 < group3 < group4 < group5"

risk_warnings:
  - level: high/medium/low
    item: 风险项名称
    description: 详细说明

version_control:
  spec_version: "1.0"
  created_by: "agent"
  reviewed_by: "human"
  status: pending  # pending / confirmed / rejected
```

注意：
1. 所有数值不要加引号，字符串加引号
2. calculation_steps 必须按执行顺序列出
3. 如果涉及差分转单季度，action 为 transform，method 为 diff_quarterly
4. 如果涉及同比，action 为 transform，method 为 yoy，lag_periods 为 4
5. 如果涉及环比，action 为 transform，method 为 qoq，lag_periods 为 1
6. 如果涉及过滤，action 为 filter，condition 写 Python 条件表达式（如 "roe_mrq_lag4 > 0"）
7. 如果涉及行业内排名，action 为 rank，method 为 industry_rank
