> ICM / VICM / VICR / CMC（行业）+ MCMC（市场）共 5 因子。月频，日频可算。
> 复现资产：`scripts/comomentum_cmc.py`（CMC算法+图20金标准+论文对齐回测）、
> `scripts/comomentum_family_verify.py`（5因子族 raw/neu 对论文）。

## 1. 因子定义与经济直觉
个股过去 20 日窗口，按排序键取若干日，加权其【所属行业指数收益】（半衰期 wᵢ=2^(−(i−1)/(n−1))）：
- ICM(top5,纯涨幅) / VICM(top5,涨幅×量) / VICR(bottom15,涨幅×量) / CMC=VICM−VICR / MCMC(CMC换中证全指)

经济直觉："个股是否与所属行业共振大涨"。因子值全部来自行业收益，**个股仅用于"挑哪几天"**
（论文 line 833）。"挑哪几天"= 个股大涨日是否撞上行业强势日 = 共振信号。

## 4. 核心洞察①：论文口径 = 行业市值中性化（跨因子坐实）
**neu 版 5 因子全部对齐论文**（RankIC±0.5%、ICIR±0.2）；**raw 版全部系统性偏低**。
单因子对齐可能巧合，5 因子全中是规律 → 论文报的 RankIC/ICIR 是中性化后口径（券商IC测试惯例）。
旁证：标准反转 Ret20 raw −1.40 → neu −2.05，同向印证中性化对所有因子成立。
（论文图33"市值相关14.5%"是"因子间相关性分析"用 raw 因子，与"IC测试用中性化因子"不矛盾。）

## 5. 核心洞察②：between/within 分解 —— 为何中性化反而提纯（最值钱）
CMC 横截面方差分解（2010-2023）：
| 成分 | RankIC | std | ICIR | 方差占比 |
|------|--------|-----|------|----------|
| raw CMC | +5.12% | 9.61% | 1.85 | 100% |
| **between 行业间(行业轮动β)** | **+0.25%** | 10.74% | **0.08** | 35% |
| **within 行业内(共振α)** | **+5.85%** | 6.68% | **3.04** | 65% |

- **between（"哪个行业最近强"=行业轮动）选股 IC 仅 0.25%/ICIR 0.08 ≈ 纯噪声**，却贡献大量 std。
- **within（"个股是否与所属行业共振"）IC 5.85%/ICIR 3.04 = CMC 全部 alpha**（比 raw 还高，std 更小）。
- raw = 有用的 within + 零信息高波动的 between → 信号被噪声稀释 → ICIR 腰斩。
- **行业市值中性化 = 组内 demean = 剥掉零信息的 between，只留共振 α → ICIR 翻倍**。

⟹ 中性化不是"砍掉行业信息"，而是分离"行业涨不涨"(β,没用) 与"个股是否与行业共振"(α,灵魂)，
   只保留后者。CMC 要的从来不是"押对行业"，而是"顺势而涨的个股"——天然是 within 信息。
MCMC 佐证：用市场收益(无行业间变异)，raw ICIR 2.89 本就最高、中性化提升最小，
   完美符合"signal 行业属性越重 → raw β 包袱越大 → 中性化提纯收益越大"。

## 6. 工程经验
- **成交量用后复权**（÷cum_factor）：剔除送股股本机械膨胀，使"放量"在除权前后可比；
  无除权窗口内 cum_factor 恒定 → 与原始 vol 排序完全相同（仅跨除权窗口有别，后复权更正确）。
- **生产必须用 neu 版**（raw 波动太大，β 噪声重），与项目"neu 版才是生产版"原则一致。
- ICM/VICM/VICR/CMC 用 build_ind_ret_panel 把个股映射到所属行业收益（含旧名别名，零特判）。

## 7. 与基准差距 / 改进路径
- 与论文 gap < 0.5% RankIC，主要残差：区间差半年、月度收益口径、停牌细节。已属优秀复现。
- 改进：流动性/规模过滤（标准反转 Ret20 neu −2.05 未完全到公认 −2.5~−3，疑股票池过宽）。
