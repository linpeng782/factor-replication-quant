## 一、已修复的Bug

### 1. rank算子跨日期分组问题
- **位置**: `core/operators/rank.py`
- **现象**: 行业内排名只按 `first_industry_name` 分组，未按 `date` 分组，导致跨所有日期累积排名（排名值达8万+）
- **修复**: 检测到 `date` 列存在时，按 `["date", group_col]` 分组
- **验证**: 因子值从 8万+ 降至正常范围（1~500）

### 2. rolling算子布尔判断异常
- **位置**: `core/operators/rolling.py`
- **现象**: `if on_col or on_df:` 中 DataFrame 不能直接用于布尔判断
- **修复**: `if on_col is not None or on_df is not None:`

### 3. 默认回测日期范围错误
- **位置**: `run.py`
- **现象**: 默认日期 `20200101~20231231`，导致只跑了4年数据
- **修复**: 改为 `20160101~20251231`

## 二、未解决的核心问题

### 问题1: 8期min操作几乎失效

**现象**: `all_rnk8` 的截面分布呈完美均匀分布（直方图每个bin几乎一样多）

**根本原因**: ROIC_TTM排名在相邻财报期间高度相关（公司基本面不会剧变），8期内的8个排名值几乎相同。`min`操作几乎不改变分布：
```
min(100, 102, 99, 101, 100, 103, 98, 100) ≈ 98
```

**影响**: 因子 ≈ 当前排名本身，未起到"取历史最好排名"的构建意图。

**待验证方案**:
- [ ] 增大窗口: 8期 → 20期（增加排名变化机会）
- [ ] 改用排名变化量: `rank_diff = 当前排名 - 历史最好排名`
- [ ] 检查变化日检测: ROIC_TTM是否因浮点精度导致"伪变化日"

---

### 问题2: 行业间排名尺度不一致（ind_rnk8）

**现象**: `ind_rnk8` z-score后呈极端右偏+右侧尖峰

**根本原因**:
1. **行业尺度差异**: 银行业40只股票（排名1~40）vs 机械行业500只（排名1~500）
2. **MAD去极值截断**: 左偏分布下MAD很小，上界≈150~200，大量大排名值被压缩到同一上界
3. **z-score放大堆积**: MAD截断后的堆积被推到 z≈+2.3

**影响**: 跨行业不可比，小行业"最差"排名40在数值上等于大行业"优秀"排名40。

**待验证方案**:
- [ ] 行业内pct排名（pct=True）: 消除行业间尺度差异
- [ ] 行业内z-score后再跨行业比较
- [ ] 不做标准化直接评估: 验证z-score/MAD是否是罪魁祸首

---

### 问题3: 因子方向矛盾

**现象**: Spec中 `direction: 1`（正向）与 description "数值越小越好" 矛盾

**影响**: 评估系统检测到IC为负，自动翻转因子方向（`Flipped: IC direction = -1`）。翻转后分层结果混乱（G1收益>G5）。

**待修复**: 确认因子经济学含义，统一direction与description。

---

### 问题4: 质量因子整体失效（2016-2025）

**现象**: 三个因子ICIR均<0.08，远低于有效阈值(>0.5)

| 因子 | 20d ICIR | 单调性 | LongShort Sharpe |
|------|---------|--------|-----------------|
| ind_rnk8 | 0.027 | -0.762 | -0.339 |
| all_rnk8 | 0.076 | +0.522 | -0.091 |
| dev_std8 | 0.055 | -0.219 | -0.147 |

**可能原因**:
1. A股质量因子在2016-2025期间整体失效（小盘/概念主导）
2. 因子构建逻辑与研报原文有偏差（需核对研报）
3. 评估周期偏短（5/10/20日），质量因子可能需要月度/季度调仓

**待验证**:
- [ ] 延长持有期评估（60d/120d）
- [ ] 核对研报原文，确认构建逻辑是否一致
- [ ] 对比已复现因子的表现（如roe系列）
