# gtr20 —— 换手率变化率的稳定 GTR（东吴证券 2023-05-09 系列第十三篇）

## 1. 因子定义

$$g_{i,t} = \frac{\text{turnover}_{i,t}}{\text{turnover}_{i,t-1}} - 1,\qquad
\text{GTR}_{i,t} = \text{std}\big(g_{i,t-19},\ \dots,\ g_{i,t}\big)$$

日换手率变化率（基准是**昨日**换手率）的 20 日标准差，横截面市值中性化。`direction = -1`。
研报 line 190-196。

**经济直觉（物理类比，研报 line 132）**：Turn20 是汽车的**平均速度**，STR 是速度的**稳定性**，
两者都没覆盖的是**加速度**——换手率变化率。GTR 再对加速度求稳定性，捕捉的是「换手率是持续
稳定地增长/衰减，还是脉冲式忽高忽低」。研报 line 178-184 的构造性例子：A 股每天换手增 3%
（均值 3%、std 0），B 股 10 天增 6% + 10 天增 0%（均值也 3%、std 3%），均值分不开这两只，
标准差能——A 是稳定放量的模范，B 是脉冲投机的典型。

## 2. 研报歧义与工程选择

| 歧义点 | 研报表述 | 本仓选择 |
|--------|---------|---------|
| 变化率基准 | 「今日换手率/昨日换手率 − 1」（line 192），**明确区别于 PctTurn20 的 40 日均值基准**（line 148） | 严格照做：`transform(method=qoq, periods=1)` 等价 `(x − x.shift1)/x.shift1` |
| 停牌日 | 未说明 | 长表中停牌日不存在，`shift(1)` 取上一个**有换手率的交易日** → 等价于剔除停牌日后算变化率 |
| 分母为 0 | 未说明 | qoq 把 0 分母置 NaN；rolling min_periods=20 |
| 标准差自由度 | 未说明 | ddof=1 |

## 3. 实现

`specs/gtr20/spec.yaml`：`load_panel` → `transform(qoq, periods=1)` → `rolling(agg=std, window=20)`。
raw shape=(4025, 5476)，2010-01-04 ~ 2026-07-31，非空 13,160,557（比 turn20 少 103 万——多消耗
1 日做 shift，且零换手日会击穿一整段变化率）。
生产注意同 turn20：首跑须显式 `--end-date 20260731`（默认 20260527 比面板末日早两个月）。

## 5. 非平凡洞察

1. **RankIC 精确复现（0.0389 vs 研报 0.038）**，是四个因子中与研报数值吻合最好的一个。原因是
   GTR 的构造完全不依赖换手率的绝对水平（两层比率/差分），因此对数据源口径差异（Wind vs dquant）
   和样本期差异都最不敏感。→ **口径鲁棒性最强的一个换手率因子**，跨市场/跨数据源迁移风险最低。
2. **IC 最低但 Sharpe 第二高、波动最低、单调性最高**：多空年化波动只有 3.97%（STR 8.13%、
   Turn20 9.01%、PctTurn20 6.05%），单调性 0.941。这不是矛盾——GTR 是个**弱但极稳**的信号。
   在多因子模型里，这种低波动高单调因子的配权价值远超它单看的 IC，因为它几乎不带风格暴露
   （研报 line 252-256：与全部 Barra 风格因子相关性绝对值 ≤0.04）。
3. **IC 期限结构平坦是独特性质**：5d 0.0375 / 10d 0.0391 / 20d 0.0389 —— 几乎不随 horizon 增长。
   对比 Turn20（0.065 → 0.094）和 STR（0.075 → 0.101）都是随 horizon 单调放大。说明 GTR 抓的是
   **短周期的脉冲/稳定性信息**，信息在 5 日内就已释放完，与研报 line 242「GTR 更适合作为一个
   追踪短期换手率变化率波动的因子」（40/60 日回看效果递减）完全一致。
   → 实盘含义：GTR 适合高频调仓（5 日甚至更短），不适合月频；反之 STR/Turn20 越拿越久越好。
4. **换手 66% 是四因子之最，成本是它最大的敌人**：按 30bp 双边估算年化磨损 ~10.3pp，
   17.29% 多空年化扣完只剩 7pp。**单独交易不划算**，价值必须通过「与其他换手率因子合成」实现——
   这正是研报标题「助推换手率的所有家族成员」的含义（line 7：与全系列换手率因子相关性不超过 0.1，
   且对全系列均具有加强作用）。
5. **中性化增益中等**：IC 5d 0.0364 → 0.0375（+3%），但 IC 波动 0.0655 → 0.0476（-27%），
   ICIR 0.618 → 0.919。GTR 本身已几乎无风格暴露（Barra 相关 ≤0.04），所以中性化收益主要来自
   行业维度而非市值维度——这与 Turn20（中性化后 ICIR 翻倍）形成对比。

## 6. 改进路径（优先级最高）

- **SPS_Turbo = 纯净优加(GTR, STR)**：研报 line 15 给出年化 ICIR -2.956、多空年化 44.24%、
  IR 3.905、月度胜率 85.37%、最大回撤 10.22%——比单独的 STR（37.14%）还要强一个台阶，
  且 GTR 与 STR 相关性 <0.1，合成收益是真实的分散化增益。四个基础因子已就位，这是下一步首选。
- **Turbo 系列（简单加法）**：Turn20_Turbo / STR_Turbo / PctTurn20_Turbo / SCR_Turbo
  （研报 §3.3，GTR 分别加强四个家族成员）
- **SCR**（换手率波动的变化率）尚未复现，是家族最后一块拼图
- 降换手：GTR 5 日平滑后再入模，可能以很小 IC 损失换掉一半成本
