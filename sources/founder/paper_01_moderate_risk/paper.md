# 方正证券 市场微观结构系列① 成交量激增时刻蕴含的 alpha 信息（"适度冒险"因子）

> 分析师 曹春晓，2022-04-12。原文 parsed_output/方正证券/（1）成交量激增时刻蕴含的alpha信息/full.md。
> 本文档为复现用蒸馏；任何"研报怎么定义"的论断以原文行号为准。

## 核心逻辑（原文 §2, L77-83）
利好信息→成交量激增。若激增同时价格未动→市场未认可；若激增同时价格大涨→反应过度（趋同）。
理想是"适度"：成交量激增带来**适度**的价格变化与波动。过度反应→未来反转，故所有因子 **direction = -1**。

## 成交量激增的定义（§3.1, L89-94）
1. 剔除开盘和收盘数据，仅日内分钟频；ΔV[m] = V[m] − V[m-1]（该分钟成交量相对上一分钟的增加量）。
2. 每股每日计算 ΔV 的均值 mean 与标准差 std。
3. **激增时刻** = ΔV > mean + 1·std 的分钟。
4. 例：某日第 9/10/88/200 分钟 ΔV 超阈值 → 这四个分钟为该日"激增时刻"。

## 激增时刻的价格波动 → 耀眼波动率（§3.2, L122-133）
1. "耀眼5分钟" = 激增时刻这一分钟及随后 4 分钟（共 5 分钟）。例：激增于第9分钟→第 9~13 分钟。
2. 用分钟收盘价算每分钟收益率；每个"耀眼5分钟"内收益率的 std = 该激增时刻的"耀眼波动率"。
3. **日耀眼波动率** = 当日所有耀眼波动率的均值。
4. **适度日耀眼波动率** = |日耀眼波动率 − 当日截面均值|（距市场平均水平的距离，§3.2 L128-130）。
5. **月均耀眼波动率** = 近 20 交易日"适度日耀眼波动率"的均值；**月稳耀眼波动率** = 其 std。
6. **月耀眼波动率** = 月均 与 月稳 等权合成。

## 激增时刻的价格变动 → 耀眼收益率（§3.3, L161-170）
1. 分钟收盘价算每分钟收益率。
2. **耀眼收益率** = 激增时刻【当分钟】的收益率。
3. **日耀眼收益率** = 当日所有耀眼收益率的均值。
4. **适度日耀眼收益率** = |日耀眼收益率 − 当日截面均值|。
5. **月均/月稳耀眼收益率** = 近 20 日均值 / std；**月耀眼收益率** = 二者等权合成。

## 适度冒险因子（§3.4, L192-202）
**适度冒险** = 月耀眼波动率 与 月耀眼收益率 等权合成。

## 工程映射（本仓实现）
- **reducer `minute_dazzle`（dazzle_v1）**：产逐股日频 `dazzle_vol`(日耀眼波动率) / `dazzle_ret`(日耀眼收益率)。
  纯日内 warmup=0。激增阈值、耀眼窗口、开收盘剔除分钟数为 params。
- **L3（spec 图）**：`transform cs_demean`+`abs`(适度=|x−截面均值|) → `rolling mean/std 20`(月均/月稳)
  → `rank(截面 pct)`+`compute`平均(等权合成，同 tide_complete 口径)。
- **歧义与工程选择**：①论文未给开收盘剔除的具体分钟数 → 复用 tide 的 drop_open=4/drop_close=7（同分钟数据已验证）；
  ②"等权合成"对不同量级分量用截面 pct-rank 后平均；③std 用样本 ddof=1（对齐 pandas rolling）。
