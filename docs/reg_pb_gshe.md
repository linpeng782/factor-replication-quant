## 1. 因子定义

原始描述极度模糊（"回归方程1"缺失、字段名非标准），推断为经典**分组 PB-ROE 残差模型**：

```
ROE  = net_profit_mrq_0 / total_equity_mrq_0
EP   = net_profit_mrq_0 / market_cap_3
PB   = pb_ratio_lf

filter: PB > 0 and ROE > 0

log_PB   = log(PB)
EP_med   = rolling_median(EP, 252d, min_periods=60)   # 过去一年 EP 中位数
EP_med_w = winsorize(EP_med, by=date)                  # 截面 MAD 去极值
EP_group = rank(EP_med_w, by=date, n_bins=10)          # 截面分 10 组

ROE_w    = winsorize(ROE, by=date)
log_PB_w = winsorize(log_PB, by=date)

对每个交易日 t、每个 EP 组 g：
  fit: log_PB_w = β₀ + β₁ · ROE_w + ε    （组内截面 OLS）
  因子值: ε
```

**经济直觉**：PB-ROE 是估值经典锚，但不同"盈利质量层"的 PB-ROE 斜率不同。先按 EP 分组，再在组内回归，残差 ε 代表"同类盈利质量中，该股票是否被异常定价"。
- ε > 0：PB 被高估 → 预期收益低
- ε < 0：PB 被低估 → 预期收益高

direction = -1。

## 2. 歧义与工程选择

| # | 歧义点 | 选择 | 理由 |
|---|---|---|---|
| 1 | `pb_if` | `pb_ratio_lf` | 米筐市净率主字段 |
| 2 | `roe_mrq` | 自行计算 `NP / Equity` | 米筐无标准 ROE 字段 |
| 3 | `ep` | `net_profit_mrq_0 / market_cap_3` | 单季度盈利收益率 |
| 4 | "回归方程1" | `log(PB) ~ ROE`（含截距） | 最经典的 PB-ROE 线性关系 |
| 5 | 分组数 | 10 组 | 平衡组内样本量与斜率区分度 |
| 6 | 去极值 | MAD winsorize（n=3） | 截面去极值标准做法 |

---

## 3. ⭐ 关键洞察：分组回归 > 全截面回归

不同 EP 组的 PB-ROE 斜率不同（高 EP 组斜率 ≈ 2.0，低 EP 组 ≈ 0.8）。全截面回归会拟合出"平均斜率"≈1.3，导致：
- 高 EP 组中等 ROE 股票被系统性低估 → 残差 ε > 0（误判为高估）
- 低 EP 组中等 ROE 股票被系统性高估 → 残差 ε < 0（误判为低估）

**残差被斜率混杂污染。** 分组后组内斜率一致，残差才是纯粹的定价偏差。

实证支持：单调性 **+0.964**（全截面通常 < 0.85）。

## 5. 与基准的差距

| 指标 | 基准 | 复现 | 差异 |
|------|------|------|------|
| IC | 0.025 | 0.043 | **+73%** |
| ICIR | 0.531 | 0.400 | **-25%** |

**更强但更不稳定的。** 原因推断：
1. **股票池差异（主因）**：基准大概率在窄池子（沪深300/中证800）测试。全指~5500只含大量小票，PB 受题材/流动性驱动，ROE 解释力弱，残差噪声大
2. **min_samples=15**：极端日小分组样本不足置 NaN，增加日度 IC 波动
3. **去极值/EP 定义差异**
