# roic_ttm_all_rnk8 — 单季度 ROIC_TTM 全市场排名最小值

## 因子定义

**名称**：`roic_ttm_all_rnk8`  
**中文名**：过去8期ROIC_TTM全市场排名的最小值  
**类别**：质量 / 财务  
**方向**：正向

## 经济含义

与 `roic_ttm_ind_rnk8` 的唯一区别：**排名范围是全市场，不分行业**。

全市场排名更能反映公司的绝对竞争力，不受行业属性影响。某些行业（如银行、地产）整体ROIC偏低，用全市场排名可以更公平地跨行业比较。

## 计算公式

```
roic_ttm_all_rnk8 = min(过去8个财报期的全市场排名)
```

## 计算链路

与 `roic_ttm_ind_rnk8` 完全相同，仅 Step 4（排名）改为全市场排名。

## 参数配置

| 参数 | 值 |
|------|-----|
| 股票池 | 全市场 |
| 时间范围 | 2016-01-01 ~ 2025-12-31 |
| 滚动窗口 | 8个财报期 |
| 最小期数 | 4期 |
| 排名方法 | `method='min'` |
