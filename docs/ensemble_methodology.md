# 模型集成方法论：从排序平均到名额分配

> 2026-07-01 沉淀。背景：滚动 LGBM 模型（2025 年训练）vs 固定 LGBM 模型（2017 年训练）在 2026 H1 的集成实验。

---

## 1. 问题背景

| 模型 | 训练区间 | 2026 H1 累计收益 | 超额收益 |
|---|---|---|---|
| 固定 LGBM | 2005~2017 | 6.16% | -2.39% |
| 滚动 LGBM | 2015~2025 | 14.57% | +6.03% |

两个模型选股重叠度仅 21%（top-100），预测分 Spearman 相关 0.656——有集成空间。

**目标**：集成后回测收益不低于滚动单模型（14.57%），且超额曲线更稳定。

---

## 2. 第一次尝试：排序平均（失败）

### 方法

```python
# 逐日截面排名分位（0~1）
r_rank = rank(rolling_pred) / N
f_rank = rank(fixed_pred)  / N

# 加权平均
ensemble = 0.6 * r_rank + 0.4 * f_rank

# 取 top-100
top100 = ensemble.nlargest(100)
```

### 结果

| 指标 | 集成 v1 | 滚动单模型 |
|---|---|---|
| 累计收益 | **3.31%** | 14.57% |
| 超额收益 | -5.23% | +6.03% |

**集成比两个单模型都差**——3.31% 远低于滚动的 14.57%，甚至低于固定的 6.16%。

### 根因分析

排序平均的本质是**求共识**，不是加权投票：

```
集成分 = 0.6 × 滚动rank + 0.4 × 固定rank
```

一只股票要进 top-100，需要**两个模型 rank 之和最高**，而不是某个模型特别看好。这天然倾向于选"两个模型都还行但不突出"的折中股票。

实证验证（第一天 top-100）：
- 集成 top-100 中属于滚动 top-100：53 只
- 集成 top-100 中属于固定 top-100：55 只
- **几乎对半开，0.6/0.4 权重完全没体现**
- 24 只股票两个模型的 top-100 都没有——是"两边都还行"的折中选股

持仓重叠度也印证了这一点：
- 集成 vs 固定重叠 49 只（更接近固定）
- 集成 vs 滚动重叠 42 只

**结论**：排序平均在 top 端抹平了权重差异，0.6/0.4 变成了 ~0.5/0.5。固定模型 2026 H1 失效，给它 50% 发言权等于拖死集成。

---

## 3. 第二次尝试：名额分配（成功）

### 核心思路切换

**从"排序求共识"切换到"名额按权重分配"**：

```
top-100 = 滚动 top-60 + 固定 top-40（去重后补足）
```

权重直接体现为持仓名额数量，不再经过排序平均的"折中效应"。

### 实现

```python
# 名额分配
n_rolling = int(100 * 0.6)  # 60
n_fixed   = 100 - n_rolling  # 40

# 各模型独立选股
r_top = rolling_pred.nlargest(n_rolling).index
f_top = fixed_pred.nlargest(n_fixed).index

# 合并去重，不足 100 则从集成 rank 补足
top100 = list(r_top) + list(f_top)  # 去重
if len(top100) < 100:
    # 从 0.6*r_rank + 0.4*f_rank 的候选池补足
    ...

# top-101~500 按集成 rank 填充（回测引擎候选池用）
```

### 验证（第一天 top-100）

- 集成 top-100 中属于滚动 top-60：**60 只**（全部包含）
- 集成 top-100 中属于固定 top-40：**40 只**（全部包含）
- 滚动 top-60 ∪ 固定 top-40 去重后 87 只，补了 13 只

**权重精确体现为持仓名额。**

### 回测结果

| 指标 | 集成 v3 | 滚动单模型 | 集成 vs 滚动 |
|---|---|---|---|
| 紧计收益 | 14.66% | 14.57% | +0.08% |
| 超额收益 | +6.11% | +6.03% | +0.08% |
| 最大回撤 | -12.14% | -12.22% | +0.08% |
| 夏普 | 1.27 | 1.26 | +0.01 |

**集成不输滚动单模型**，目标达成。

---

## 4. 集成的真正价值：超额曲线质量

最终收益只多了 0.08%，但超额曲线质量显著提升：

| 指标 | 集成 v3 | 滚动单模型 |
|---|---|---|
| **超额峰值** | **+15.38%**（6/16） | +13.23%（5/20） |
| **创新高天数** | **30/116（26%）** | 22/116（19%） |
| **最长回撤段** | **21 天** | 47 天 |
| 超额 Sharpe | 0.897 | 0.887 |

### 关键观察

1. **集成超额峰值高 2.15 个点**：滚动在 5/20 见顶后回吐 7.7 个点，集成在同期继续创新高到 6/16
2. **集成创新高频率高 36%**：30 天 vs 22 天
3. **集成把滚动的 47 天长回撤拆成两段**（21 天 + 18 天），中间还创新高一次

### 为什么更稳定？

两个模型选了 79% 不同的股票，逐日超额收益不完全同步（相关性 0.91 但非 1.0）。名额分配集成后：
- 滚动 60 只贡献主 alpha
- 固定 40 只虽然整体弱，但在滚动回撤的时段（如 2~3 月）偶尔有效，起到对冲作用
- 分散效应抹平了各自的波动尖峰

**更稳定的超额曲线 = 更敢上仓位**。杠杆 2 倍时，集成的超额峰值 30%，回撤只多 1.67 个点——风险调整后收益更优。

## 5. 方法论总结

### 两种集成方式的本质区别

| | 排序平均 | 名额分配 |
|---|---|---|
| **逻辑** | 求两个模型 rank 的加权共识 | 各模型独立选股，按权重分配名额 |
| **top 端权重** | 抹平（0.6/0.4 → ~0.5/0.5） | 精确（60 只 + 40 只） |
| **选股倾向** | "两边都还行"的折中股 | 各自 top 的并集 |
| **弱模型影响** | 50% 发言权，严重拖累 | 40% 名额，可控 |
| **适用场景** | 两个模型实力相当 | 两个模型实力不等 |

### 何时用名额分配

- 两个模型实力差距大（一个明显强于另一个）
- 需要**保证集成不输强模型**（强模型给 ≥50% 名额）
- 关注超额曲线稳定性而非绝对收益

### 何时用排序平均

- 两个模型实力相当
- 追求最大化分散效应
- 不在意单个模型的权重是否精确体现

### 后续方向：动态权重

固定 60/40 仍非最优——固定模型在 4~6 月失效时，40% 名额是纯拖累。动态权重方案：

```
每个调仓日，回看过去 20 天 IC：
  w_rolling = IC_rolling / (IC_rolling + IC_fixed)
  w_fixed   = IC_fixed   / (IC_rolling + IC_fixed)
  n_rolling = round(100 × w_rolling)
```

滚动强时给 88% 名额，固定强时给 60% 名额——自适应市场风格切换。
