# 长端动量 1.0 / 2.0（开源证券 2022-11-26，开源量化评论 67）

因子定义与研报原文引证见 `../paper.md`。本文记录实现与复现结论。

## 1. 因子原理

A 股长端涨跌幅（Ret160）整体呈反转，但这是**假象**：高振幅交易日（过度反应）的
涨跌幅度大，主导了长端涨跌幅（Ret_high 与 Ret160 相关 84.8%，Ret_low 仅 4.9%），
其强反转掩盖了低振幅日里真实存在的动量。按振幅切割、只保留低振幅 70% 交易日的
收益加总，就把"过度反应噪声"剔掉，露出 A 股罕见的**长期动量**效应。

经济直觉：振幅低 = 当日无剧烈分歧/无情绪冲击 = 价格变化更多来自基本面信息的缓慢
定价 → 有持续性；振幅高 = 情绪驱动 → 均值回复。

2.0 的四处改进：切割指标改 (H−L)/前收；剔除涨跌停/停牌日；切割对象改**日超额收益**
（去市场 beta，使不同股票被选中的日期集合不同也可比）；结果做 **20 日反转中性**。

## 2. 实现（新建件）

| 件 | 说明 |
|---|---|
| `scripts/build_amplitude_panels.py` | 后复权 H/L/C → `amp_panel`（(H−L)/前收，2.0）+ `amp_hl_panel`（H/L−1，1.0） |
| `data_fetching/normal_day_dquant.py` | dquant `get_limit` 涨跌停价 × 未复权 close × combo_mask `is_suspended` → `normal_day_panel`（1=正常交易日，实测 97.17%） |
| `core/operators/rolling_sorted_subset.py` | **新 L3 算子**：窗口内按 sort 列升/降序取 frac 比例子集后 sum/mean，支持 mask 列剔除无效日 |
| `specs/long_mom_1`、`specs/long_mom_2` | 2 个 spec（1.0 三步；2.0 七步） |

算子实现要点（矢量化）：长表 → (date × stock) 宽表 → 按股票列分块（默认 64 列）
`sliding_window_view` → `argsort` → `take_along_axis` → `cumsum`，用 `cumsum[k−1]`
一次取"前 k 小"的和；无效日把排序键置 `+inf` 沉底、值置 0，`k = floor(n_valid × 0.7)`
自动随有效日数缩放。全市场 160 日窗口约 3.5 分钟。

2.0 的 20 日反转中性直接复用 APM 的 `cross_section_regress` + `RET20_PANEL_PATH`。

## 4. 非平凡洞察

1. **RankICIR 口径反推**：研报未说明 ICIR 是否年化。用 2.0 的胜率 79.49% 反推：
   若月频比值 2.75 → Φ(2.75)=99.7% ≫ 79.5%；若年化 2.75 → 月频 0.794 → Φ(0.794)=78.6%
   ≈ 79.5% ✓。故开源口径是**年化**。（对比：华泰 2016 动量研报的"IR 比率"是**月频比值**，
   由其 IC>0 占比栏同法可验。）**不同券商 IR 口径不一致，必须用胜率反推校准，否则
   对照结论会差 √12 倍。**
2. **1.0 复现偏低 1.4pct 的根因**：1.0 未剔停牌/涨跌停日。A 股停牌日在原始面板里
   振幅=0 且收益=0/NaN，会被优先划入"低振幅 70%"，等于往动量信号里掺零——研报 1.0
   大概率做了某种停牌处理但表1 未写。这正是研报把"剔除涨跌停停牌"列为 2.0 首要改进的
   原因；我们的 1.0 忠实照表1 实现（不剔），所以偏弱，**差距本身印证了改进 2 的价值**。
3. **cs_demean 的隐含选择**：研报"市场涨跌幅均值"未定义是指数收益还是个股等权均值。
   取**全 A 个股等权均值**（cs_demean）——若用指数（市值加权）会给小盘股留下系统性正
   alpha，破坏横截面可比性。
4. **涨跌停必须自建 mask**：仓库 combo_mask 只有 `is_limit_up`，**没有跌停**。用
   `get_limit` 的涨跌停价与未复权 close 比（容差 1e-4）自建，反例占比 2.83%，量级合理
   （A 股涨跌停日占比约 1.5%~3%）。用后复权 close 比会全错。
5. **`pivot_table` 会塌缩时间轴（踩坑）**：长表→宽表若直接 `pivot_table`，「该列全为
   NaN 的日期」整行被丢弃 → 滚动窗口把不相邻的日子当成相邻，窗口静默错位。全市场
   场景下每个交易日总有股票有值、日期轴恰好完整所以不出错（已 bit-exact 验证修复
   前后因子面板完全一致），但单股/小样本调试时必现。两个新算子已强制
   `reindex(index=长表全部日期, columns=长表全部股票)`。**任何"长表→宽表→滚动"的
   算子都要显式重建轴，别信 pivot 的默认行为。**
6. **20 日反转中性贡献多大**：手算 AlphaRet_low 与最终因子（去反转后）在单股上相关
   0.96，但月频 RankIC 从 ~5% 提到 6.03%——中性化剥掉的是**截面**上的反转暴露，
   单股时序相关性高不代表截面无变化。

## 5. 与基准差距 / 改进路径

- 1.0 与论文差 1.4pct：可做变体 `long_mom_1__excl_limit`（1.0 定义 + 剔涨跌停停牌）
  定量分离"停牌污染"的贡献。
- 研报还测了分域（沪深300/中证500/中证1000）与行业聚合版（自由流通市值加权）：
  行业版需自由流通市值数据（仓库目前只有总市值 `market_cap_3`），暂未复现。
- 与现有因子的相关性未测；研报称与换手/波动 −16%、与反转 +4.6%，接入 ML 前建议跑
  `scripts/factor_correlation.py --pattern 'long_mom*'` 确认无冗余。
