## 二、数据频率扫描结果

| 编号 | 研报 | 数据频率 | 日内操作 | 核心计算 |

| (2) | 潮汐因子 | **分钟级** | 成交量"低→高→低"潮汐过程识别 | 局部极值检测 → 涨潮/退潮能量计算 |
| (3) | 勇攀高峰 | **分钟级** | 收益波动比 | 分钟级波动率 → 收益波动比 → 协方差 |

| (5) | 云开雾散 | **分钟级** | 波动率的波动率（模糊性） | 分钟级波动率 → 波动率的波动率 → 与成交额相关性 |

即使是看起来最像日频的第 (8) 篇草木皆兵，文中也明确写了："取股票 1 分钟频率的行情数据，计算每分钟收盘价相对上一分钟收盘价的涨跌幅"。

## 三、计算范式提炼：惊人的一致性

把这 8 篇的因子构建链路抽象后，发现它们共用**同一套模板**：

```
分钟数据 (1m close/volume)
    │
    ▼
┌─────────────────┐
│  日内指标计算    │  ← 差分/均值/标准差/条件筛选/窗口切片/局部极值/相关性
│  (240分钟→1值)  │
└─────────────────┘
    │
    ▼
日频聚合 (groupby date → mean/std/sum/corr)
    │
    ▼
┌─────────────────┐
│  20日滚动统计    │  ← rolling(20).mean() / .std()
│  (月度因子化)    │
└─────────────────┘
    │
    ▼
截面处理 (减均值/绝对值/zscore/正交化)
    │
    ▼
合成 (等权/IC加权)
```

**核心洞察**：扩展一次基础设施，8 篇全部受益。

## 四、元操作扩展清单

当前系统的元操作（`fetch/compute/filter/transform/rank`）基于**日频 wide 面板**假设，完全无法支持分钟级数据。要复现这 8 篇，需要新增以下算子：

| 算子 | 用途 | 覆盖研报 | 扩展难度 | 优先级 |
|------|------|---------|---------|--------|
| `fetch(frequency='1m')` | 分钟级数据获取 | 8/8 | ⭐ 低 | P0 |
| `diff` | 时间轴差分（分钟成交量差） | 5/8 | ⭐ 低 | P0 |
| `pct_change` | 分钟收益率 | 6/8 | ⭐ 低 | P0 |
| `groupby_aggregate` | 日内→日频聚合 | 8/8 | ⭐⭐ 中 | P0 |
| `rolling` | 20 日滚动 mean/std | 8/8 | ⭐⭐ 中 | P0 |
| `cross_sectional` | 截面减均值/绝对值/zscore | 5/8 | ⭐ 低 | P0 |
| `orthogonalize` | 市值+行业正交化 | 8/8 | ⭐⭐ 中 | P1 |
| `cov_corr` | 协方差/相关系数 | 2/8 | ⭐⭐ 中 | P1 |
| `dazzle_window` | 条件时序窗口切片（激增→后续4分钟→聚合） | 1/8 | ⭐⭐⭐⭐ **高** | P1 |
| `local_extrema` | 局部极值识别（低→高→低潮汐过程） | 1/8 | ⭐⭐⭐ 中高 | P1 |

**最难的两个算子**：
- `dazzle_window`：标记激增时刻 → 取后续 4 分钟 → 聚合。仅第 (1) 篇"适度冒险"需要。
- `local_extrema`：日内成交量低→高→低的潮汐过程识别。仅第 (2) 篇"潮汐"需要。

其余 8 个算子都是**标准时间序列操作**，扩展后不仅这 8 篇能用，其他任何"分钟级→日频→月频"的研报都能复用。

## 六、现实约束：分钟级数据获取速度

当前系统的预计算数据（mask、vwap）都是**日频**的。分钟级数据需要实时从 rqdatac 拉取：

- 全 A 约 5000 只股票 × 每天 240 分钟 × 10 年 ≈ **30 亿数据点**
- `get_price(frequency='1m')` 拉取速度较慢，全市场一次可能需要 **数小时**
- 但好在 8 篇研报的因子逻辑都是**月频选股**，最终只需要**月频因子值**
- 可以按"月"或"季度"分批拉取分钟数据，计算完后丢弃中间结果

**这不是元操作的瓶颈，是数据工程的瓶颈**，可以通过分块计算 + 缓存日频中间结果来解决。

理由：

## 附录：每篇研报的核心因子逻辑速记

### (1) 适度冒险因子
- **输入**：分钟级成交量、分钟级收盘价
- **步骤**：
  1. 成交量增加量 = vol - vol.shift(1)
  2. 日内 mean/std，标记激增时刻 = diff > mean + std
  3. 耀眼 5 分钟 = 激增时刻 + 随后 4 分钟
  4. 耀眼波动率 = 耀眼 5 分钟收益率.std()
  5. 日耀眼波动率 = 日内所有耀眼波动率.mean()
  6. 适度日耀眼波动率 = |日值 - 截面均值|
  7. 月均/月稳 = rolling(20).mean()/std()
  8. 月耀眼波动率 = 月均 + 月稳 等权
  9. 同理计算月耀眼收益率
  10. 适度冒险 = 月耀眼波动率 + 月耀眼收益率 等权

### (2) 完整潮汐因子
- **输入**：分钟级成交量、分钟级收盘价
- **核心**：识别日内成交量"低→高→低"的一次潮汐过程
- **子因子**：全潮汐因子、强势半潮汐因子、弱势半潮汐因子
- **合成**：完整潮汐 = 等权合成

### (3) 勇攀高峰因子
- **输入**：分钟级收盘价
- **核心**：收益波动比（收益率/波动率）与波动率的协方差
- **子因子**：灾后重建因子（负向）、勇攀高峰因子（正向）

### (4) 球队硬币因子
- **输入**：日频开盘价/收盘价/换手率 + 日内收益率
- **核心**：用波动率/换手率变化量判断股票是"可知"（硬币，反转）还是"不可知"（球队，动量）
- **子因子**：日间反转、日内反转-波动翻转、日内反转-换手翻转、隔夜距离等

### (5) 云开雾散因子
- **输入**：分钟级收盘价、分钟级成交额/成交量
- **核心**：波动率的波动率（模糊性），以及模糊性大时投资者的卖出急切程度
- **三种衡量**：模糊性与成交额相关性、模糊时成交额占比、模糊时成交量占比

### (6) 飞蛾扑火因子
- **输入**：分钟级收盘价 + 日频最高最低价
- **核心**：
  - 单利/连续复利收益率差 → 日跳跃度 → 月跳跃度
  - 日内振幅分类：太阳型（非跳跃）vs 火把型（跳跃）
- **合成**：月跳跃度 + 修正振幅 等权

### (8) 草木皆兵因子
- **输入**：分钟级收盘价 + 日频收益率
- **核心**：
  - 分钟收益率标准差
  - 日收益率偏离市场的程度（惊恐度）加权日收益率
- **改进方向**：波动率加剧、个人投资者交易比、注意力衰减

### (9) 水中行舟因子
- **输入**：分钟级收盘价、分钟级成交额、日频开盘价
- **核心**：
  - 合理收益率 = 过去 20 日日内收益率均值
  - 相对开盘收益率 = 分钟收盘价/当日开盘 - 1
  - 高位/低位成交额分离（基于是否超过合理收益率）
- **子因子**：随波逐流因子（高位时跟随市场好）、孤雁出群因子（市场分化时不跟随好）
