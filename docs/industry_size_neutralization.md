# 行业市值中性化：方法与数据结论

> 管线：raw → cleaned（MAD+zscore+mask）→ **neu（强制行业市值中性化 + 再标准化）** → 评估
> 算法：`alpha_shared.neu.neutralize`；数据：中信行业面板 + 总市值面板（stock-data-fetching 产出）

## 1. 方法

每个交易日横截面 OLS，取残差作为中性化因子：
```
factor ~ [行业 one-hot(中信一级) | log(market_cap_3)],  hasconst=False
```
- 满行业哑变量已张成常数项，无需截距；残差 = 剥离行业归属 + 市值规模后的纯 alpha
- **FWL 向量化**：行业组内去均值 y 与 log_size → 残差 y 对残差 log_size 过原点回归 → 残差。
  与逐日满哑变量 OLS **逐元素相同**（`alpha-shared/tests/test_neu.py` 对拍 statsmodels，容差 1e-10）
- 残差再做横截面 zscore（restandardize）
- 有效截面 = factor & industry & size 三者同时非空；当日 < max(行业数+2, 30) 整天 NaN

## 2. 数据结论（22 个基本面因子，5d，2016–2025）

| 指标 | 改善/恶化 | 均值变化 | 结论 |
|---|---|---|---|
| **ICIR** | **22↑ / 0↓** | 0.187 → 0.301 (**+61%**) | 唯一全员改善：IC 稳定性普遍提升 |
| **多空 Sharpe** | **20↑ / 2↓** | 1.16 → 1.84 (**+58%**) | 行业/市值暴露贡献大量波动，去掉后风险调整收益近翻倍 |
| IC5d 幅度 | 15↑ / 7↓ | +0.0153 → +0.0161 | 基本持平：损失"假 IC"(规模/行业 tilt)，留下更纯 alpha |
| 单调性 | 9↑ / 13↓ | 0.818 → 0.872 | 均值升靠救活破损因子，多数微降 |

**一句话**：中性化用"原始 IC 持平"换"ICIR +61%、Sharpe +58%"——去系统性行业/市值押注，留干净稳定 alpha。

## 3. 三类分化

1. **估值类（PE/PB）= IC 输家、Sharpe 赢家**：IC 部分来自小盘效应，市值中性化掉了；但 ICIR/Sharpe 大涨（reg_pe_hist：IC 0.044→0.038↓，Sharpe 2.11→3.05↑）。
2. **质量/现金流类 = 全面赢**：net_oper_cash_flow_ttm 最大赢家（IC×2、ICIR×4、Sharpe 0.18→1.63 ×9）；roe_mrq_new Sharpe 0.38→1.61。
3. **能救活破损因子**：roic_ttm_all_rnk8 单调性 −0.675 → +0.859（原本反向）。

## 4. ⚠️ 关键洞察：行业相对因子应豁免中性化

`roic_ttm_ind_rnk8`（**行业内** ROIC 排名）多空 Sharpe **0.51 → 0.14**（2/2 个 Sharpe 下降之一）。
原因：它构造上**已是行业相对**因子，再做行业中性化 = 行业维度被抽两遍，核心信号也被抽掉。

**结论**：强制中性化对绝大多数因子净正面，作为默认生产口径合理；但应给"构造上已含中性化维度"的因子（如 `*_ind_rnk*`）开豁免——不是退回全 opt-in，而是少数例外。
