# lb_flow_resid — 大单残差资金流强度（开源系列12）

## 因子定义

    S_t = a + b·Ret20_t + ε_t        （逐日截面 OLS，L183）
    lb_flow_resid = ε_t

S 为 lb_flow_s3（大单 S3），Ret20 为过去 20 日后复权收益（RET20_PANEL_PATH）。
研报逻辑（L215 alpha 切分）：大单净流入伴随上涨 → S3 多头暴露反转负 alpha，回归剥离后
剩纯净正 alpha。研报：IC 从 0.042 提至 **0.054**，IR 从 2.69 提至 **3.96**。

## 复现结果：残差化后信号几乎消失

| 指标 | 研报 (2013-2021.4) | 复现 (同区间) | 复现 (2016-2025 管线) |
|---|---|---|---|
| IC | +0.054 | **-0.016**（月度） | IC5d ≈ 0（cleaned, dir=-1 翻转后 +0.0009） |
| 多空 | IR 3.96 | — | 分层反单调（mono=-0.78），多空无利可图 |

年度 IC 符号漂移剧烈：2013/14 为正 → 2015-2020 为负 → 2021-2023/2025 转正 → 2024 负。
无稳定方向，不可用。

## 为什么研报的"残差增强"在 jy 口径下失效

研报的逻辑链是：S3 有正 alpha（大单预见性）+ 负 alpha（反转暴露）→ 剥离 Ret20 后正 alpha
更纯。jy 口径下 S3 本身没有正 alpha（见 docs/lb_flow_s3.md：主动买入是反转信号，IC -0.036），
其预测力**主要就是**与 Ret20 共线的那部分（截面秩相关 ~0.48，与研报"R²较高"一致）；
截面回归把这部分剥掉后，残差里没有独立信息，只剩噪声 → IC≈0 且符号漂移。
这反过来印证了根源诊断：研报 alpha 依赖 Wind"挂单分档"语义中的订单结构信息，
jy"成交分档"数据中不含该信息。

## 工程要点

- spec 链 = lb_flow_s3 五步 + load_panel(RET20_PANEL_PATH) + cross_section_regress
  （复用 APM 的截面回归算子，min_samples=30，含截距）。
- Ret20 面板为 close-close 后复权口径（scripts/build_ret20_panel.py），与研报"涨跌幅"一致。
- 若未来接入 Wind 口径资金流，此 spec 结构可直接换数据面板复跑验证研报结论。
