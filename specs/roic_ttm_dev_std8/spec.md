# roic_ttm_dev_std8 — 单季度 ROIC_TTM 稳定性因子

## 因子定义

**名称**：`roic_ttm_dev_std8`  
**中文名**：过去8期ROIC_TTM标准差的倒数  
**类别**：质量 / 财务  
**方向**：正向（标准差越小 → 因子值越大）

## 经济含义

ROIC_TTM 的稳定性反映了公司盈利质量。盈利波动大的公司往往经营风险高、业绩不可预测；而盈利稳定的公司通常具备更强的竞争优势和更成熟的商业模式。

本因子直接衡量 ROIC_TTM 在过去8个财报期中的稳定性，不涉排名，计算更简单。

## 计算公式

```
roic_ttm_dev_std8 = 1 / std(过去8个财报期的ROIC_TTM)
```

## 计算链路

1. 获取全市场 ROIC_TTM 时间序列
2. 识别每只股票的财报期（ROIC_TTM 变化日）
3. 在财报期上计算 rolling(8, min_periods=4).std()
4. 取倒数
5. ffill 到所有交易日

## 参数配置

| 参数 | 值 |
|------|-----|
| 股票池 | 全市场 |
| 时间范围 | 2016-01-01 ~ 2025-12-31 |
| 滚动窗口 | 8个财报期 |
| 最小期数 | 4期 |
| 聚合函数 | std → 取倒数 |
