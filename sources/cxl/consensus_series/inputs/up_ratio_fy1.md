# up_ratio_fy1 — 分析师盈利预测上调比例 (fy1)

**类别**：景气/动量 | **方向**：+1（上调比例越高 → 景气向上 → 预期收益越高）

## 研报释义（consensus.png）
计算方法参考 adj_pct_fy1，只是第 3 步以「上调分析师数 / 所有分析师数」作为因子值。

## adj_pct_fy1 流程（共享）
1. 剔除非个股报告，仅保留首序分析师的报告记录；将一个月内发布的盈利预测偏离幅度
   在 1% 范围内的报告视为重复报告并删除；在首年度财务报告发布时点更新预测年度。
2. 对每篇报告，找到同一股同一预测期分析师撰写的上一篇报告，计算盈利预测调整幅度。
3. 每天获取可回溯区间内发布的报告，每个分析师取其最新预测记录，
   求上调分析师数 / 所有分析师数作为因子值（分析师数目不足 3 个的置为 nan）。
   可回溯区间定义为上一期财务报告发布时点的前 5 天至今。

## 工程实现
- 数据源：`get_consensus_indicator(fiscal_year=Y, date_rule='rice_create_tm')` 报告级明细。
- 剔非个股：report_main_id 数字主体 == order_book_id 主体（行业/策略研报 report_main_id 不匹配）。
- 首序分析师 = author 逗号分隔首位；1% 内偏离视为重复剔除（不更新基准）。
- fy1 滚动：fiscal_year=Y 在 [Y-05-01, (Y+1)-04-30] 区间作 fy1（年报披露后切换）。
- 可回溯区间近似为 lookback=180 天（约两个财报周期；分析师覆盖稀疏，用半年更稳）。
- 截面聚合每股活跃首序分析师最新观点，上调数/总数；活跃分析师<3 置 NaN。
