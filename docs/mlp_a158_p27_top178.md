# MLP 固定训练模型 —— 完整沉淀

> 2026-07-02。PyTorch FCNN 二分类选股模型，全周期 6.5 年回测验证，是当前最强单模型。

---

## 1. 方案概述

使用 alpha158 + p27 共 178 个因子，训练一个 3 层全连接神经网络（FCNN），逐日截面中位数二分类选股。一次性固定训练（2005~2017），样本外预测 2020~2026。

**全局累计 550.53%，年化 35.04%，夏普 1.20，IR 1.40**——全面超越两个 LGBM 模型。

## 2. 模型详情

| 项 | 值 |
|---|---|
| 模型 ID | `mlp_a158_p27_top178` |
| 模型类型 | PyTorch FCNN（全连接神经网络） |
| 训练方式 | 一次性固定训练，无 split_mode（时间切分：train/valid/test 三段） |
| 训练区间 | 2005-01-01 ~ 2017-11-30（train 段） |
| 验证区间 | 2018-01-01 ~ 2019-11-30（valid 段，用于早停） |
| 样本外区间 | 2020-01-01 ~ 2026-06-30（test 段，即回测区间） |

### 网络结构

```
输入(178) → Linear(178, 80) → Tanh → Dropout(0.3)
         → Linear(80, 20)   → Tanh → Dropout(0.3)
         → Linear(20, 1)    → Sigmoid → 输出概率
```

- 激活函数：Tanh
- 权重初始化：Xavier Uniform
- 输出：Sigmoid 概率（0~1），越大越看好

## 3. 特征

| 项 | 值 |
|---|---|
| 因子来源 | alpha158-dquant（158 个技术因子）+ kysec-dquant/paper_27_microstructure（27 个微观结构因子） |
| 原始因子数 | 185 个（158 + 27） |
| 排除因子 | 3 个 p27 稀疏因子（`peak_ridge_price_ratio`、`valley_ridge_price_ratio`、`ridge_relative_vwap`，覆盖仅 ~22%） |
| 最终特征数 | **178 个**（185 - 3 - 4 个 NaN 不一致被数据对齐丢弃） |
| 特征选择 | **无**（`select_method=null`，全特征直喂 MLP，不做 SHAP/GBDT 降维） |
| 排除原因 | 这 3 个因子依赖「峰/岭/谷」分钟喷发判定，天然稀疏。MLP 走 `has_factor=ALL`（要求全部特征非 NaN），保留这 3 个会剔除 78% 样本。排除后保留率从 22% 提升到 87%，样本量 295 万 → 1166 万 |

### 与 LGBM 的特征差异

| | LGBM（A/B） | MLP |
|---|---|---|
| 因子来源 | 相同（alpha158 + p27） | 相同 |
| 特征选择 | SHAP GBDT 选 top-64 | **无选择，全 178 特征** |
| 排除稀疏因子 | 不排除（LGBM 原生吃 NaN） | 排除 3 个稀疏因子 |
| has_factor 策略 | NONE（允许 NaN，不剔除行） | **ALL**（要求全部 178 特征非 NaN，任一 NaN 即排除该行） |

## 4. 标签与标准化

### 标签：BinaryMedian（逐日截面中位数二分类）

```
median[t] = median( ret[t, pool[t]] 非NaN )    # pool = 样本池（can_train）
y[t,j]    = 1 if ret[t,j] > median[t] else 0   # 当日收益 > 中位数 → 1，否则 → 0
```

- **二分类目标**，不是回归
- 逐日截面计算中位数，当日收益高于中位数标记为正样本（1），低于标记为负样本（0）
- 对齐 `ml_ht.dataset.binarize_labels`

### 标签与 LGBM 的差异

| | LGBM（A/B） | MLP |
|---|---|---|
| 标签类型 | ExcessReturn（超额收益，回归） | **BinaryMedian（二分类 0/1）** |
| 标签含义 | 截面等权 demean 超额收益 | 当日收益 > 截面中位数 → 1 |
| 标签标准化 | WholeSetRobustZ（有状态） | **无**（二分类标签不标准化） |

### 特征标准化：DailyCrossSectionMAD（逐日截面 MAD，无状态）

```
逐日：
  1. MAD 去极值：clip(x, median - 5×1.4826×MAD, median + 5×1.4826×MAD)
  2. Z-score：(x - mean) / std
```

- **逐日截面**计算，统计量来自当日截面，不跨日、不持久化
- **无状态**：每天用当天截面重新算，不需要保存 scaler
- 对齐 `ml_ht.dataset.preprocess`

### 标准化与 LGBM 的差异

| | LGBM（A/B） | MLP |
|---|---|---|
| 特征标准化 | WholeSetRobustZ（全样本 Robust Z，有状态持久化） | **DailyCrossSectionMAD（逐日截面 MAD，无状态）** |
| 统计来源 | train 段全部 (日×股) 单元 | 当日截面 |
| 跨日水位 | 保留（median/MAD 由 train 段拟合，固定不变） | 不保留（每天重算，只看当天截面相对排名） |

## 8. 与 LGBM 的差异化

### 持仓重合度

| 对比 | 重合度均值 |
|---|---|
| MLP vs A 固定 | **23.84%** |

| A 固定 vs B 滚动 | 36.08% |

**MLP 与 LGBM 的持仓重合度仅 24%，远低于两个 LGBM 之间的 36%**——模型架构差异带来的选股差异化比训练方式差异更大。

### 预测截面 rank-IC

| 对比 | rank-IC 均值 |
|---|---|
| MLP vs A 固定 | 0.7872 |
| MLP vs B 滚动 | 0.6833 |
| A 固定 vs B 滚动 | 0.7996 |

### 差异化根因

MLP 与 LGBM 的差异来自三个层面：

1. **标签不同**：MLP 用二分类（>中位数=1），LGBM 用回归（超额收益）。二分类只关心排序，不关心幅度；回归关心幅度
2. **标准化不同**：MLP 逐日截面标准化（只看当天相对排名），LGBM 全样本标准化（保留跨日水位）
3. **架构不同**：MLP 是非线性神经网络（178→80→20→1），LGBM 是树模型（leaf-wise 分裂）。MLP 能捕捉因子间的非线性交互，LGBM 擅长捕获阈值效应

## 9. 集成价值

### MLP + LGBM 集成实验结果

| 集成方案 | 累计 | 年化 | vs MLP | 回撤 | 最长回撤段 |
|---|---|---|---|---|---|
| **MLP 单模型** | **550.53%** | **35.04%** | — | -38.26% | 172 天 |
| MLP+A 5050 | 504.62% | 33.46% | -46% | **-36.69%** | **120 天** |
| MLP+A 7030 | 512.77% | 33.75% | -38% | -38.42% | 172 天 |
| MLP+B 7030 | 448.09% | 31.38% | -102% | -38.88% | 176 天 |

### 结论

- **收益维度**：没有集成方案超越 MLP 单模型。MLP 太强，任何比例混入 LGBM 都会稀释 alpha
- **风控维度**：MLP+A 5050 的最长回撤段从 172 天缩短到 120 天（-30%），IR 1.42 略超 MLP 1.40
- **集成价值在风控不在收益**：如果追求绝对收益最大化，MLP 单模型最优；如果看重回撤恢复速度，MLP+A 5050 值得考虑
