# turn20 —— 传统换手率因子（东吴证券 2021-05-15 系列第七篇）

## 1. 因子定义

$$\text{Turn20}_{i,t} = \frac{1}{20}\sum_{k=0}^{19} \text{turnover}_{i,t-k}$$

过去 20 个交易日日均换手率，横截面市值中性化。`direction = -1`。

**经济直觉**：换手率是关注度/流动性/投机热度的代理。换手率高 → 交易拥挤、散户参与度高、
未来一个月更易下跌；换手率低 → 关注度不足、被冷落，未来更易上涨（流动性溢价 + 反转）。
研报 line 91：全 A 月度 IC -0.072，年化 ICIR -2.10。

## 2. 研报歧义与工程选择

| 歧义点 | 研报表述 | 本仓选择 |
|--------|---------|---------|
| 调仓频率 | 每月月底 | 日频滚动（每日回看 20 日），评估用日频 forward return + 5 日调仓分层 |
| 中性化 | 横截面市值中性化 | neu 阶段做行业 one-hot + log 市值双重中性化（更严） |
| 换手率口径 | 未说明（Wind） | dquant `get_turnover_rate.today`，单位 % |
| 缺失日处理 | 未说明 | `load_panel` stack 后停牌日不存在，rolling 按「可用交易日」计数；min_periods=20 |

## 3. 实现

`specs/turn20/spec.yaml`：`load_panel(TURNOVER_RATE_PANEL_PATH)` → `rolling(agg=mean, window=20)`。
raw shape=(4025, 5476)，2010-01-04 ~ 2026-07-31，非空 14,190,233 单元。

⚠️ **生产注意**：`run.py` 默认 `--end-date` = `DEFAULT_END_DATE`(20260527)，比换手率面板末日
(2026-07-31) 和 alpha158 / htsec 动量因子末日(2026-07-31)都早。首次跑完必须显式
`--end-date 20260731` 补齐，否则该因子进模型时会成为**共同覆盖末日的短板**，
把整个特征集的可用区间往前拉两个月。

**与研报对照**：研报月度 IC -0.072、多空年化 33.41%、IR 1.90。我们 20d IC 0.094、多空年化
28.98%，量级和方向都对得上；差异来自区间不同（研报含 2006-2015 小市值黄金期，我们从 2016 起）
+ 日频 vs 月频 + 双重中性化。

## 5. 非平凡洞察

1. **中性化对该因子是纯增益**：IC 均值只从 0.0623 升到 0.0647（+4%），但 IC 波动从 0.179 砍到
   0.099（-45%），ICIR 直接翻倍（0.51 → 0.96），多空 Sharpe 从 1.39 → 3.22。说明 Turn20 的收益
   波动大头来自**行业和市值的共同暴露**（换手率天然和小市值高度相关），剔掉后 alpha 几乎无损。
   → 这个因子必须用 neu 版本进模型，cleaned 版本等于自带一份小市值 beta。
2. **空头端贡献远大于多头端**：neu 下 G1 年化 -13.55%，G5 +13.39%，而基准（全市场等权）大致在
   G3 的 +7.7% 附近 → 空头超额 -21pp，多头超额 +5.7pp。纯多头组合只能吃到很小一部分，
   这个因子的价值主要在**剔除高换手垃圾股**（做负向过滤器），而非选多头。
3. **单调性在两端更强、中间平坦**：G2→G4 只从 3.70% 爬到 10.20%，G5 才跳到 13.39%。分层信号
   集中在极端组，说明用作特征时非线性变换（分位数/rank）比线性用值更合适（LGBM 天然处理）。
4. **换手率低 = 换手率稳定？不完全**：Turn20 与 STR 的分层图形几乎同形（都强单调），但 STR 的
   G5 年化 16.37% 明显高于 Turn20 的 13.39%，且 STR 多空 Sharpe 4.57 > 3.22。研报 line 161 的
   论断在我们的日频口径下**同样成立**：稳定性比绝对水平更有信息。

## 6. 与基准的差距 & 改进路径

- 研报多空年化 33.41% vs 我们 28.98%：主因样本期。研报 2006-2021 全段，小市值/高换手股的
  反转效应在 2016 前更强；2017 之后 A 股换手率因子普遍衰减。
- 改进方向：① STR / GTR 组合（研报 SPS_Turbo 年化 44.24%，IR 3.905）；② 剔除 Vol20
  （STR_deVol20 思路）；③ 参数敏感性（40 日、60 日回看，研报 line 246 显示 20 日最优）。
