## 研报核心结论

- line 161：「在根据换手率对股票进行评价时，换手率的绝对数值、相对变化固然重要，但**换手率的稳定性**也同样不容忽视，且回测结果显示，稳定性中包含的选股信息更为有效」
- line 139：PctTurn20 整体效果**不如**传统 Turn20，主因 2020/09 之后样本外大幅回撤
- line 175：STR 与 Turn20、PctTurn20 相关性较高；正交化后残差 IC 均值 -0.029、ICIR -2.02，仍有选股能力
- line 177：STR 与传统波动率因子 Vol20 的平均月度相关系数 **0.59**；剔除波动率的 STR_deVol20 收益端有损失（年化 32.98%）但 IR 升至 3.14

## 复现口径选择（工程决策）

1. **日频滚动而非月频截面**：本仓因子面板统一日频（每日回看 20 日），评估侧用日频 forward return + 分层回测，与研报月末调仓不完全等价，量级可比、绝对数值不可直接对齐。
2. **PctTurn20 的 40 日基准不含当日**：原文「再往前取 X 个交易日」读作从当日之前起算，故实现为 `rolling(40).mean().shift(1)`，总窗口 61 日。
3. **换手率原料**：`TURNOVER_RATE_PANEL_PATH`（dquant `get_turnover_rate.today`，单位 %）。均值/标准差类因子对单位是线性/齐次的，截面 zscore 后与小数口径等价。
4. **min_periods = window**（严格），停牌缺失日在长表中不存在，rolling 按「可用交易日」计数。
