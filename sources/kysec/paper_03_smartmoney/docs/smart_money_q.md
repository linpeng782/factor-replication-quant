# 聪明钱因子 Q（方正2016原始版 + 开源系列3 2.0版）— 复现沉淀

> 覆盖 smart_money_q（β=0.1, 2.0）与 smart_money_q__beta05（β=0.5, 原始）。论文蒸馏见 ../paper.md。

## 1. 因子定义（数学 + 直觉）
"聪明钱"=机构单笔大单、报价激进 → 分钟级"价格波动大、量未必大"。逐股过去 10 日分钟：
- 聪明度 **S = |R_t| / V_t^β**（R=分钟收益, V=分钟成交量）。β 大→重视低量；β 小→重视大波动。
- 按 S 降序取**成交量累计前 20%** 分钟 = 聪明钱交易。
- **Q = VWAP_smart / VWAP_all**：聪明钱成交均价 / 全体成交均价。
- **Q>1**=聪明钱买在相对高位（逢高出货/悲观）→ 未来跌；**Q<1**=逢低吸筹→未来涨。**direction=-1（反转）**。

## 2. 实现（已有件，本次建库+评估）
- reducer `minute_smartmoney`（warmup=lookback=10）：跨日 10 日池化在 reducer 内（不可拆成日内+L3滚动→必须进 reducer，引擎用 warmup 喂 overlap）。
- 闭式：每日按 [t-9,t] 连续切片，argsort S 降序，cumsum 量占比 searchsorted cutoff（含跨阈值那一分钟）。
- 复权稳健：S 用 |R|（日内分钟比值，cf 抵消）；Q 是同窗口 VWAP 比值。
- 两个 superset：`sm_v1`(β=0.1) / `sm_v1_b05`(β=0.5)，内容寻址 hash 隔离。

## 3. 复现结果（月频 RankIC / 年化 ICIR，月末截面 vs 次月收益）
| 因子 | 窗口 | 月频 RankIC | 年化 ICIR | 负相关占比 | 论文目标 |

| smart_money_q (β=0.1, 2.0) | 2014-2019 | **-8.36%** | -6.08 | 99% | **RankIC -8.5%** ✓ |
| smart_money_q (β=0.1, 2.0) | 2016-2025 | -7.37% | -4.47 | 93% | — |

**2.0 版 RankIC -8.36% ≈ 论文 -8.5%，本质命中**；方向负向、99% 月份负相关，极稳。
**β=0.1 / β=0.5 = -8.36% / -3.11% ≈ 2.7×**，定量复现 2.0 论文"IR 1.7→3.67（≈2.7×）"的 β 改进核心论点。

## 4. 非平凡洞察
1. **β 的威力**：2.0 唯一核心改动是 β 0.5→0.1，论文 IR 1.7→3.67。我用同 reducer 两套 params（内容寻址 hash 隔离）并列产出 β=0.1/β=0.5，直接复现"调一个指数翻倍"的结论——验证了工厂"变体=改 params→新 superset，旧的不动"的设计。
2. **第三种 reducer 形态落地**：聪明钱是"跨日池化在 reducer 内"型（10日累计量分位选择，不可分解为日内归约+L3线性滚动），warmup=10 由 reducer 自报。与 tide/dazzle（warmup=0 纯日内）、prv（warmup=40 嵌套rolling）构成 reducer warmup 谱系。
3. **方向天然为负（反转）**，与 APM（正向）相反——聪明钱测"机构成交价位"（高位=出货），APM 测"知情时段方向"（隔夜=看多）；同是微观结构，经济含义不同导致方向相反。

## 5. 工程选择 / 待验证
- **预过滤（原始注[2] L483）**：原始论文排序前先剔除分钟量最小 1/5。当前 reducer 未做；2.0 未强调。RankIC -8.36% 已对齐 → 暂不加（加了可能更贴 -8.5%，留作微调）。
- S3 变体 `|R|/ln(V)`（论文 IR 3.74 最优）：当前 reducer 是 V^β 幂式，ln(V) 需加 reducer 的 S-mode 参数，留待后续。

## 6. 与基准差距
- 2.0 RankIC -8.36% vs 论文 -8.5%：差 0.14pct，评估窗口/股票池/正交方式微差，已属命中。
- ICIR 量纲：论文"IR 3.67"是多空组合年化 IR（Sharpe型），与本仓 ICIR（IC均值/IC标准差×√12）非同一指标；本仓 ICIR -6.08 量级合理（负向、高显著）。
