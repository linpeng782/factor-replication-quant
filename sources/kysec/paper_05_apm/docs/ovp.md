# OVP 隔夜下午累计差（开源微观结构系列5 §"W式切割"）

> APM 族最强因子。完整族沉淀（构造/洞察/全因子对比）见 [apm_new.md](apm_new.md)。

## 定义
OVP = 近20日累计隔夜收益 − 近20日累计下午收益 = Σr_overnight − Σr_pm（rolling sum 20）。
隔夜对未来正向预测、下午负向预测（论文L218）→ **OVP 越大未来收益越高，direction=+1**。
**无需指数回归、无需滚动回归**——只用 reducer 段收益 + rolling sum + 相减，是 APM 族最低成本切入。
